# 監控事件目錄

每個事件只對應一個目標和一個結果。接入、開關、元件定位和鏈路欄位見[前端監控](./monitoring)。欄位組用於描述 `params`，通過 `OpenVikingMonitoringEventMap[事件名]['params']` 獲取公開型別。

| `client_request_fail`    | `ComponentName`  | `所屬元件區域` | `RequestFault` | 同次請求在配置解析、傳輸、讀體或既有業務錯誤判定失敗；HTTP 200 錯誤外殼也失敗。呼叫中止不報，合法非 JSON 響應不額外改判。         |
