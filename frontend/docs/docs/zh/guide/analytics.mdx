# 埋點

透過 `OpenVikingProvider.analytics` 接收業務元件和區塊的操作、結果及曝光事件，由宿主對接自己的埋點平臺。

## 接入

根 Provider 省略 `analytics` 時關閉採集，不建立埋點事件、曝光觀察器或操作計時。配置 `onEvent` 後開啟；元件和區塊無需增加埋點 Props。

```tsx
import { OpenVikingProvider } from '@openviking/react/client';
import type { OpenVikingAnalyticsOptions } from '@openviking/react/client';

const analytics = {
  onEvent(event) {
    // 在宿主接入層呼叫自己的 SDK，並補充頁面、來源和使用者身份。
    hostAnalytics.track(event.name, {
      ...event.params,
      instanceId: event.instanceId,
    });
  },
} satisfies OpenVikingAnalyticsOptions;

<OpenVikingProvider analytics={analytics}>{children}</OpenVikingProvider>;
```

`hostAnalytics` 和 `children` 由宿主提供。元件庫不包含埋點 SDK，不主動向埋點平臺發請求。

### 選擇事件

省略 `events` 時接收全部內建事件，傳 `[]` 時不接收任何事件。每個名稱都受到型別約束，按名稱判斷後，`params` 收窄為該事件的引數型別。

```tsx
const analytics = {
  events: [
    'openviking_file_preview_copy_path_click',
    'openviking_file_browser_search_success',
  ],
  onEvent(event) {
    if (event.name === 'openviking_file_browser_search_success') {
      console.log(event.params.result_count, event.params.duration_ms);
    }
  },
} satisfies OpenVikingAnalyticsOptions;
```

### Provider 作用域

巢狀 Provider 省略 `analytics` 時繼承外層，傳 `false` 時關閉當前子樹，傳配置物件時替換外層配置。一個採集點只投遞給最近的有效配置，不同時上報內外兩層。切換配置不重新請求業務資料，也不回放關閉期間的操作。

`onEvent` 可以返回 `Promise<void>`。上報不阻塞業務操作；同步拋錯或 Promise 拒絕均被隔離，庫不自動重試或快取事件。需要重試、取樣或批次傳送時，在宿主接入層處理。

## 事件約定

- 事件名固定為 `openviking_<目標>_<事件>`。複製路徑與複製正文、接入指南與程式碼塊分別定義，不用一個事件兼指多個目標。
- 業務元件的提交或點選只表達使用者意圖；實際執行所在的區塊或內部執行器報告成功、失敗。宿主接管執行時，庫不推斷宿主的業務結果。
- `console_command_accepted` 表示關聯非同步任務已受理；關聯任務全部成功後才發 `console_command_success`。任務查詢失敗不作為任務執行失敗。
- `file_preview_download_start` 表示瀏覽器下載已發起，不能據此判斷檔案已儲存到本地。
- `file_preview_save_success` 的 `version_status: 'not-created'` 表示正文儲存成功但版本未建立；`'unknown'` 表示儲存介面未明確版本狀態。
- 取消與失敗分開。請求因元件解除安裝、作用域切換而失效時，不補發舊請求的成功或失敗。

### 曝光

`*_show` 和 `directory_tour_start` 在目標進入可視區域且頁面處於前臺後觸發，要求相交區域寬高均大於零；隱藏、載入中的正文和後臺預覽層不計曝光。同一目標在同一次展示週期內只報一次，重渲染、滾出後滾入、標籤頁切回不會重複。彈窗關閉後重新開啟、引導切換步驟或切換預覽目標會開始新週期。

曝光使用 `IntersectionObserver`，不判斷目標是否被其他元素遮擋。不支援該 API 的環境跳過自動曝光。關閉配置後再次開啟不會補發歷史操作；尚未曝光且此時可見的目標可以首次上報。

### 公共欄位與資料範圍

| 欄位         | 說明                                       | 型別                                       |
| ------------ | ------------------------------------------ | ------------------------------------------ |
| `name`       | 固定事件名，用於收窄 `params`              | `OpenVikingAnalyticsEventName`             |
| `params`     | 該事件的引數；無引數的事件為 `{}`          | `OpenVikingAnalyticsEventMap[typeof name]` |
| `instanceId` | 採集點例項標識，不是使用者、帳號或資源標識 | `string`                                   |

`operation_id` 關聯同一次操作的提交與結果；`duration_ms` 是從操作開始到當前階段的毫秒數，`step_index` 從零開始。`error_kind` 只提供固定分類，不包含錯誤原文。

`has_filters` 表示當前檢索方式是否啟用了實際支援的顯式篩選。預設根目錄不計入篩選，僅選擇時間欄位而未設定日期也不計入。

內建事件不採集完整 URI、檔案路徑、檔名、查詢詞、命令原文、訊息和檔案正文、郵箱、密碼或 API Key。頁面、來源、使用者身份及平臺自定義欄位由宿主在 `onEvent` 中補充。

## API

型別均從 `@openviking/react/client` 匯出。

### OpenVikingAnalyticsOptions

| 引數      | 說明                                 | 型別                                                         | 預設值       |
| --------- | ------------------------------------ | ------------------------------------------------------------ | ------------ |
| `onEvent` | 接收篩選後的事件，上報異常不影響業務 | `(event: OpenVikingAnalyticsEvent) => void \| Promise<void>` | 必填         |
| `events`  | 選擇要接收的內建事件                 | `readonly OpenVikingAnalyticsEventName[]`                    | 全部內建事件 |

`OpenVikingProviderProps.analytics` 的型別是 `OpenVikingAnalyticsOptions | false`，根 Provider 預設關閉。`OpenVikingAnalyticsEventMap` 提供逐事件引數對映，`OpenVikingAnalyticsEvent` 是可以按 `name` 收窄的聯合型別。
