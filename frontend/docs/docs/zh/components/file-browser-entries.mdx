# FileBrowserEntries 檔案瀏覽入口

可選 `locale: 'zh-CN' | 'en-US'` 覆蓋最近的模組或 Provider；均未配置時預設 `en-US`。已有 `labels` 可逐項覆蓋。業務內容仍由宿主提供。

檔案瀏覽區域頂部的入口條：連線 Agent 與匯入資源。固定兩個入口，可通過右側抽屜展示 `AgentConnect` 接入面板。

## 基礎用法

```tsx
import { FileBrowserEntries } from '@openviking/react/components/file-browser-entries';
import '@openviking/react/components/file-browser-entries/style.css';

<FileBrowserEntries
  locale="zh-CN"
  agentConnect={{ apiKey: 'demo-api-key', locale: 'zh-CN' }}
  onImportResources={openImportFlow}
  labels={{
    connectAgent: '連線 Agent',
    importResources: '匯入資源',
    close: '關閉',
  }}
/>;
```

## 顯示與隱藏

傳入 `agentConnect` 即可開啟內建的 `AgentConnect` 右側抽屜。引數直接透傳給接入面板，其中 `apiKey` 必填，`locale` 可選並繼承入口條語言；入口條樣式已包含面板樣式，無需額外匯入。抽屜從右側滑出，可通過關閉按鈕、遮罩或 Esc 關閉；窄容器內可橫向滾動面板。

`onConnectAgent` 仍支援宿主自定義流程；與 `agentConnect` 同時傳入時，作為點選通知觸發。兩者都省略才隱藏連線入口；同時省略 `onImportResources` 和 `renderImportResources` 隱藏匯入入口。

沒有可見入口時整塊不渲染。只顯示一個入口時不畫分隔線——線分隔的是兩個相鄰項，只剩一個就無從分隔。

```tsx
<FileBrowserEntries locale="zh-CN" onImportResources={openImportFlow} />
```

## 自定義匯入入口

`renderImportResources(trigger)` 接收已包含圖示、文案和 `onImportResources` 回撥的原生按鈕。宿主可以用自己的 `Popover` 包裹它，或返回替代節點；無需為了顯示入口傳入空回撥。返回 `null` 時隱藏入口及對應分隔線，所有入口都隱藏時整塊不渲染。

下面的 `Popover` 與 `ImportMenu` 由宿主提供。預設按鈕直接作為 `Popover` 的 `children`，供其接管 ref、事件與定位。保留預設按鈕時會保留點選回撥；完全替換節點時，由宿主繫結互動。

```tsx
<FileBrowserEntries
  locale="zh-CN"
  renderImportResources={(trigger) => (
    <Popover trigger="click" content={<ImportMenu />}>
      {trigger}
    </Popover>
  )}
  labels={{ importResources: '匯入資源' }}
/>
```

## 屬性

| 屬性                    | 型別                                   | 預設值           | 說明                                         |
| ----------------------- | -------------------------------------- | ---------------- | -------------------------------------------- |
| `locale`                | `'zh-CN' \| 'en-US'`                   | 繼承上層 / en-US | 內建中英文文案。                             |
| `agentConnect`          | `AgentConnectProps`                    | —                | 啟用內建右側接入抽屜                         |
| `onConnectAgent`        | `() => void`                           | —                | 點選通知；單獨使用時接入宿主自定義流程       |
| `onImportResources`     | `() => void`                           | —                | 預設匯入按鈕的點選回撥                       |
| `renderImportResources` | `(trigger: ReactElement) => ReactNode` | —                | 包裝或替換預設匯入按鈕；返回 `null` 隱藏     |
| `labels`                | `FileBrowserEntriesLabels`             | —                | 入口及抽屜 `close` 文案，未覆蓋項跟隨 locale |
| `className`             | `string`                               | —                | 容器附加類名                                 |

## 與模組的關係

`FileBrowser` 已內建本元件，宿主直接在模組上傳入 `agentConnect`、`onImportResources` 與可選的 `renderImportResources`，並通過 `labels.entries` 定製文案。獨立組裝檢視時仍可單獨使用本元件。
