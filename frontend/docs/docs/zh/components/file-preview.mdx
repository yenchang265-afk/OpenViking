# FilePreview 檔案預覽

帶頁籤的檔案預覽。宿主給出內容與檔名，元件負責格式識別、頁籤行、內容區標題行與正文。

當前是佔位實現：頁籤外殼、編輯流程與成功通知已就位並可互動，檔案正文尚未接入渲染器，先以純文本降級展示。檢視後續按本文契約重寫。

## 基礎用法

至少傳入一個頁籤。檔案頁籤攜帶 `source`，內容頁籤攜帶由宿主自行渲染的節點。

```tsx file="../../_demos/file-preview-basic.tsx" preview

```

## 兩類頁籤

| 型別              | 由誰渲染     | 典型用途               |
| ----------------- | ------------ | ---------------------- |
| `kind: 'file'`    | 元件         | 檔案原文、原始碼、文件 |
| `kind: 'content'` | 宿主原樣渲染 | 看板、圖譜、摘要       |

兩類共享外殼——頁籤行、路徑麵包屑、複製路徑與標題行插槽。差異在正文怎麼來，以及預覽/原始碼切換隻屬於檔案頁籤：內容頁籤需要多種檢視時在 `content` 裡自行實現。

當前啟用哪個頁籤由元件內部維護。需要從外部切換時用 ref 控制代碼：

```tsx
const previewRef = useRef<FilePreviewHandle>(null);
previewRef.current?.setActiveTab('dashboard');
```

## 內容從哪來

`source` 接受三種互斥輸入，按順序取第一個有值的：

- `content` —— 內聯文本，會被包成以 `fileName` 命名的 `File`。
- `file` —— `File` 或 `Blob`，直接透傳。
- `url` —— 可訪問連結，元件不自行鑑權。

`fileName` 必填，同時決定格式識別與頁籤預設標題。

## 狀態

載入中、失敗與格式不支援都不是 props，由元件根據內容與檔名判定。三種狀態都可以通過插槽替換：

- `slots.loadingFallback`
- `slots.errorFallback`
- `slots.unsupportedFallback`

宿主提供非同步 `editing.save` 執行儲存，可選提供 `editing.loadContent` 讀取完整文本；返回 `undefined` 表示放棄編輯，拒絕時顯示讀取失敗提示。儲存失敗時保留草稿並顯示錯誤。`editing.onSave` 僅通知儲存成功，`editing.onCancel` 通知草稿已被丟棄。儲存中阻止重複提交與頁籤切換。

執行能力與通知分開：操作成功後才觸發對應的 `on…` 回撥，失敗時不觸發。省略方法時隱藏或停用對應入口，通知本身不承擔操作。正文 URI 互動待接入 FileViewer 時啟用。

## 屬性

| 屬性     | 型別                                             | 預設值 | 說明                                 |
| -------- | ------------------------------------------------ | ------ | ------------------------------------ |
| `tabs`   | `readonly [FilePreviewTab, ...FilePreviewTab[]]` | 必填   | 至少一個頁籤，初始展示第一個。       |
| `labels` | `FilePreviewLabels`                              | 英文   | 所有頁籤的預設文案，頁籤可逐項覆蓋。 |
| 其餘屬性 | `HTMLAttributes<HTMLDivElement>`                 | —      | 標準 div 屬性。                      |

### 頁簽字段

兩類頁籤共有：

| 屬性                 | 型別                         | 預設值  | 說明                                   |
| -------------------- | ---------------------------- | ------- | -------------------------------------- |
| `key`                | `string`                     | 必填    | 頁籤唯一標識。                         |
| `title`              | `ReactNode`                  | 檔名    | 頁籤行顯示內容；內容頁籤必填。         |
| `icon`               | `ReactNode`                  | 按格式  | 頁籤圖示。                             |
| `labels`             | `Partial<FilePreviewLabels>` | —       | 覆蓋該頁籤的文案。                     |
| `disabled`           | `boolean`                    | `false` | 停用該頁籤。                           |
| `onOpenParent`       | `(path: string) => void`     | —       | 上級目錄成功開啟後觸發；失敗時不觸發。 |
| `onCopyPath`         | `(path: string) => void`     | —       | 路徑複製成功後通知。                   |
| `showViewModeSwitch` | `boolean`                    | `true`  | 預覽/原始碼切換；僅檔案頁籤生效。      |
| `slots`              | `FilePreviewHeaderSlots`     | —       | `actions`、`titleExtra`。              |

檔案頁籤額外提供：

| 屬性            | 型別                            | 預設值 | 說明                                                                                       |
| --------------- | ------------------------------- | ------ | ------------------------------------------------------------------------------------------ |
| `source`        | `FilePreviewSource`             | 必填   | 內容與檔名。                                                                               |
| `operations`    | `FilePreviewOperations`         | —      | 非同步執行能力：`openParent(path)`、`download()`、`openUri(uri)`，均返回 `Promise<void>`。 |
| `resources`     | `readonly FileViewerResource[]` | —      | 伴隨資源，例如 3D 貼圖。                                                                   |
| `editing`       | `FilePreviewEditing`            | —      | 編輯能力；不傳即只讀。                                                                     |
| `slots`         | `FilePreviewFileTabSlots`       | —      | 增加三類狀態兜底。                                                                         |
| `onCopyContent` | `(text: string) => void`        | —      | 正文複製成功後通知。                                                                       |
| `onDownload`    | `() => void`                    | —      | 下載操作成功後觸發；失敗時不觸發。                                                         |
| `onOpenUri`     | `(uri: string) => void`         | —      | 正文資源成功開啟後觸發；失敗時不觸發。                                                     |

```tsx
import { FilePreview } from '@openviking/react/components/file-preview';
import '@openviking/react/components/file-preview/style.css';
```

複製由元件完成。檔案頁籤提供 `source.path` 時顯示路徑複製按鈕；沒有可複製文本時，正文複製按鈕停用。兩類回撥都接收已經複製成功的值，失敗時不觸發；省略回撥不影響複製，宿主無需再次執行復制。

## 無障礙

頁籤行使用 `role="tablist"` 與 `role="tab"` 按鈕並上報 `aria-selected`。圖示按鈕都帶 `aria-label` 與 `title` 提示。路徑麵包屑只在傳入 `operations.openParent` 時才可點選。

## 類名

類名帶 `ov-` 字首。塊名為 `ov-file-preview`，元素使用 `ov-file-preview__<元素>`。

| 類名                               | 元素     | 用途                           |
| ---------------------------------- | -------- | ------------------------------ |
| `ov-file-preview`                  | 根節點   | 縱向佈局與基礎排版。           |
| `ov-file-preview__tab-row`         | 頁籤欄   | 可橫向滾動的頁籤行。           |
| `ov-file-preview__tab`             | 頁籤     | 單個頁籤，帶 `aria-selected`。 |
| `ov-file-preview__tab-title`       | 頁籤標題 | 截斷的頁籤文本。               |
| `ov-file-preview__header`          | 頭部     | 路徑行與操作區。               |
| `ov-file-preview__breadcrumb`      | 麵包屑   | 上級目錄導航按鈕。             |
| `ov-file-preview__header-actions`  | 操作區   | 切換、按鈕與擴充套件操作。     |
| `ov-file-preview__action`          | 圖示按鈕 | 方形純圖示控制元件。           |
| `ov-file-preview__button`          | 按鈕     | 次要按鈕。                     |
| `ov-file-preview__button--primary` | 按鈕     | 主要（儲存）按鈕。             |
| `ov-file-preview__switch`          | 切換組   | 編輯與預覽切換容器。           |
| `ov-file-preview__switch-item`     | 切換項   | 單個切換，帶 `data-active`。   |
| `ov-file-preview__body`            | 滾動區域 | 內容滾動容器。                 |
| `ov-file-preview__pre`             | 預覽文本 | 只讀文本內容。                 |
| `ov-file-preview__textarea`        | 編輯器   | 可編輯文本域。                 |
| `ov-file-preview__state`           | 狀態面板 | 整高的載入、空態與錯誤檢視。   |

## 實現範圍

元件渲染外殼並通知成功的操作。讀取、儲存、下載與導航由宿主提供執行能力，成功通知不執行這些操作。
