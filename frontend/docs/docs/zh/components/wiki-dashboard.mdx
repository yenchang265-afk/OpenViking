# WikiDashboard Wiki 看板

展示 Wiki 目錄或檔案裡的衝突：目錄檢視列出有衝突的檔案，檔案檢視列出每條衝突的詳情和修復記錄。

## 何時使用

- 需要在檔案瀏覽中檢視 Wiki 的衝突概覽，並跳轉到具體檔案或衝突時。
- 需要自己決定資料來源、操作按鈕和頁面佈局時：元件只負責展示，不發起請求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 時，看板已經內建，不需要單獨接入。

## 引入

```tsx
import { WikiDashboard } from '@openviking/react/components/wiki-dashboard';
import '@openviking/react/components/wiki-dashboard/style.css';
```

## 程式碼演示

### 基礎用法

## API

### WikiDashboard

| 引數             | 說明                                                                              | 型別                                                                                                                            | 預設值                   |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| kind             | 展示模式，資料載入中也能確定                                                      | `'directory' \| 'file'`                                                                                                         | 必填                     |
| data             | 與 `kind` 對應的展示資料，未提供時顯示載入或錯誤狀態                              | `WikiDirectoryData`（目錄）、`WikiFileData`（檔案）                                                                             | -                        |
| loading          | 列表為空時顯示載入狀態                                                            | `boolean`                                                                                                                       | `false`                  |
| error            | 列表為空時顯示錯誤狀態                                                            | `Error \| null`                                                                                                                 | -                        |
| onRetry          | 點選重試時觸發，元件不自行發起請求                                                | `() => void`                                                                                                                    | -                        |
| onOpenUri        | 目錄檢視：點選檔案時觸發，引數為該檔案的 URI；檔案檢視：點選路徑時觸發            | `(uri: string) => void`（目錄）、`() => void`（檔案）                                                                           | -                        |
| onOpenDashboard  | 目錄檢視：開啟該檔案的看板時觸發，未提供時回退到 `onOpenUri`                      | `(uri: string) => void`                                                                                                         | -                        |
| defineActions    | 為每一行定義操作按鈕，省略或返回空陣列時不顯示操作區                              | `(uri: string) => readonly WikiDashboardAction[]`（目錄）、`(conflict: WikiConflict) => readonly WikiDashboardAction[]`（檔案） | -                        |
| slots            | 替換渲染異常的展示內容，見[錯誤展示插槽](../guide/getting-started#自定義錯誤展示) | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }`                                                           | -                        |
| labels           | 覆蓋介面文案                                                                      | `Partial<WikiDashboardLabels>`                                                                                                  | -                        |
| locale           | 介面語言，規則見[國際化](../guide/i18n)                                           | `'zh-CN' \| 'en-US'`                                                                                                            | 繼承上級，預設 `'en-US'` |
| className、style | 外觀與佈局，其餘 HTML 屬性透傳到根元素                                            | HTML 屬性                                                                                                                       | -                        |

### WikiDirectoryData

| 引數              | 說明                                                      | 型別                | 預設值 |
| ----------------- | --------------------------------------------------------- | ------------------- | ------ |
| files             | 有衝突的檔案 URI                                          | `readonly string[]` | 必填   |
| conflictFileCount | 衝突檔案數                                                | `number`            | -      |
| limited           | 檔案列表是否被截斷，為 `true` 時數量後顯示 `+` 並提示上限 | `boolean`           | -      |

### WikiFileData

| 引數      | 說明                                   | 型別                      | 預設值 |
| --------- | -------------------------------------- | ------------------------- | ------ |
| conflicts | 檔案裡的衝突                           | `readonly WikiConflict[]` | 必填   |
| path      | 要展示的文件路徑，省略時不顯示路徑區域 | `string`                  | -      |

### WikiConflict

| 引數             | 說明                                                         | 型別                                                                                                     | 預設值 |
| ---------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ------ |
| id               | 衝突的唯一標識                                               | `string`                                                                                                 | 必填   |
| matchText        | 衝突在正文中的原文片段                                       | `string`                                                                                                 | 必填   |
| description      | 衝突標題，點選後展開詳情                                     | `string`                                                                                                 | 必填   |
| reason           | 衝突原因                                                     | `string`                                                                                                 | 必填   |
| severity         | 嚴重程度                                                     | `'high' \| 'medium' \| 'low'`                                                                            | 必填   |

| resolutionSource | 修復方式                                                     | `'manual' \| 'automatic'`                                                                                | -      |
| location         | 原文片段在正文中的位置；`unique` 時帶 `start`、`end`、`line` | `{ status: 'unique'; start: number; end: number; line: number } \| { status: 'missing' \| 'ambiguous' }` | 必填   |

| 引數     | 說明                                                                 | 型別         | 預設值  |
| -------- | -------------------------------------------------------------------- | ------------ | ------- |
| key      | 操作的穩定標識，同一行內唯一                                         | `string`     | 必填    |

| disabled | 禁止點選，仍可聚焦檢視提示                                           | `boolean`    | `false` |

## 注意

- 元件沒有預設操作。`defineActions` 在渲染時呼叫，只根據當前行返回配置，不要在裡面發請求或更新狀態；可以按衝突狀態返回不同的操作。
- 元件沒有頂層 `uri` 屬性。請求和定位需要的 URI 通過 `onOpenUri`、`defineActions` 的閉包傳入。
- 切換文件時要重置篩選和展開狀態，在外層給元件設定 `key={documentId}`。
- 型別從 `@openviking/react/components/wiki-dashboard` 匯出，包根入口只匯出元件和 `WikiDashboardProps`。
