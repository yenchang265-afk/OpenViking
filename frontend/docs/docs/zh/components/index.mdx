# 元件

面向 OpenViking AI 應用的可複用檢視與檔案型別圖示。元件均為純 UI，通過 props 接收處理後的資料與狀態，通過回調錶達互動意圖，不感知介面；取數與業務聯動由模組或宿主負責。

## 可用模組

### [FileBrowserEntries 檔案瀏覽入口](./file-browser-entries)

檔案瀏覽區域頂部的入口條：連線 Agent 與匯入資源。固定兩個入口，宿主只決定顯示哪幾個與點選後做什麼，圖示、文案與分隔線由元件負責。

### [FileTree 檔案樹](./file-tree)

展平後的檔案樹，支援行渲染、選中、展開、鍵盤互動與分頁意圖上報。宿主提供有序行資料並負責載入。當前檢視為佔位實現，範圍與限制見元件詳情。

### [DirectoryTour 目錄引導](./directory-tour)

基於目錄行 DOM 錨點的六步定位引導，支援非同步定位、獨立高亮、避讓、重試與跳過；宿主負責目錄載入和完成狀態。

### [FilePreview 檔案預覽](./file-preview)

帶頁籤的檔案預覽檢視，提供標題操作、頁籤切換及純文本預覽和編輯基礎。當前檢視為佔位實現：正文尚未接入 FileViewer，先降級為純文本。應用負責提供內容與儲存行為。

### [Tui 命令控制台](./tui)

命令記錄、結果與輸入區檢視，補全、引數提示與分組命令幫助由內建 CLI 後設資料驅動。

### [ScopeSwitcher 作用域選擇](./scope-switcher)

無狀態的頭部麵包屑容器，組合獨立的 ScopeSelector 檢視。各級宿主獨立管理資料、搜尋和請求，僅選中身份參與級聯更新。

### [AgentConnect Agent 接入](./agent-connect)

Figma 接入檢視，內建主流 Agent 與 MCP、CLI、API、SDK 開發接入列表、中英文詳情和原始圖示。呼叫方提供金鑰與語言，支援例項內或受控選擇與複製反饋。

### [VikingBot 對話](./viking-bot)

對話檢視：訊息列表、輸入區與待確認互動區。按歸一化訊息模型渲染可用檢視，當前為待設計評審的佔位實現。

### [圖示](./icons)

提供音訊、PDF、簡報、影片與文字文件五種檔案型別圖示，支援自定義圖片尺寸與無障礙描述。

### [WikiDashboard Wiki 看板](./wiki-dashboard)

獨立展示 Wiki 生成效果、待確認衝突及修復記錄，通過狀態和回撥展示載入及重試。

### [ExperienceDashboard 經驗看板](./experience-dashboard)

獨立展示 Agent 經驗列表、應用效果與來源追溯，通過 props 接收展示資料和狀態。

公開包入口、樣式選擇與應用接入邊界見[快速開始](../guide/getting-started)。
