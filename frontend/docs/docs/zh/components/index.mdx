# 業務元件總覽

這裡的業務元件都是純檢視：資料由你傳入，元件不發起請求，也不需要 `OpenVikingProvider`。自帶取數的功能見[區塊](../modules/)。

### [Icons 圖示](./icons)

元件庫內建的圖示：箭頭、檔案型別、作用域層級和看板圖示以 React 元件提供，渲染為內聯 SVG；另有按檔名選擇檔案型別圖示的函式。

## 檔案與目錄

### [FileTree 檔案樹](./file-tree)

FileTree 把宿主提供的行渲染成可展開、可鍵盤操作的檔案樹。

### [FilePreview 檔案預覽](./file-preview)

帶頁籤的檔案預覽：按格式渲染檔案正文，提供路徑麵包屑、預覽與原始碼切換、文本編輯和宿主自定義操作。

### [FileBrowserActionBar 檔案瀏覽操作欄](./file-browser-action-bar)

檔案瀏覽區頂部的操作欄，固定兩個操作：連線 Agent 和匯入資源，由宿主決定顯示哪幾個以及點選後做什麼。

### [DirectoryTour 目錄引導](./directory-tour)

分步介紹目錄的非模態引導：依次定位宿主指定的目錄行，在旁邊顯示高亮和講解卡片，不改變檔案選中狀態。

## 對話與命令

### [VikingBot 對話](./viking-bot)

展示宿主提供的會話訊息，並提供輸入區和待確認互動區：傳送、停止、開啟資源等操作通過回呼交給宿主，元件不發起請求。

### [CommandConsole 命令控制台](./command-console)

終端風格的命令記錄與輸入檢視：展示命令記錄及其結果，輸入區提供命令補全和引數幫助。

## 帳號與連線

### [ScopeSwitcher 作用域選擇](./scope-switcher)

由多級獨立選擇器組成的作用域麵包屑：`ScopeSwitcher` 負責排列，每一級（例如庫、資料空間、使用者）用一個 `ScopeSelector` 展示當前值並切換。

### [AgentConnect Agent 接入](./agent-connect)

Agent 接入面板，列出主流 Agent 和 MCP、CLI、API、SDK 四種開發方式，展示接入說明和可複製的程式碼塊，其中的 API Key 預設脫敏。

### [登入與認證表單](./auth-forms)

六個元件，覆蓋選擇登入方式、郵箱或 API Key 登入、請求重置郵件、設定密碼和確認邀請。

## 資料看板

### [WikiDashboard Wiki 看板](./wiki-dashboard)

展示 Wiki 目錄或檔案裡的衝突：目錄檢視列出有衝突的檔案，檔案檢視列出每條衝突的詳情和修復記錄。

### [ExperienceDashboard 經驗看板](./experience-dashboard)

展示 Agent 經驗的使用情況：目錄檢視列出經驗檔案，檔案檢視展示單個經驗的應用效果、來源軌跡和測試材料。
