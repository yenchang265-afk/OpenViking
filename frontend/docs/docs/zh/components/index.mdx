# 元件

面向 OpenViking AI 應用的可複用檢視與檔案型別圖示。元件通過 props 接收處理後的資料和狀態，通過事件回調錶達使用者意圖；資料獲取、認證與業務流程由應用負責。

## 可用模組

### [FileTree 檔案樹](./file-tree)

展平後的檔案樹，支援行渲染、選中、展開、鍵盤互動與分頁意圖上報。宿主提供有序行資料並負責載入。當前檢視為佔位實現，範圍與限制見元件詳情。

### [FilePreview 檔案預覽](./file-preview)

帶頁籤的檔案預覽檢視，提供標題操作、頁籤切換及純文本預覽和編輯基礎。當前檢視為佔位實現：正文尚未接入 FileViewer，先降級為純文本。應用負責提供內容與儲存行為。

### [Tui 命令控制台](./tui)

已確認的命令記錄、結果與輸入區 API。當前檢視仍為佔位實現；命令補全、CLI 共享後設資料與結果渲染後續實現。

### [ScopeSwitcher 作用域選擇](./scope-switcher)

無狀態的頭部麵包屑容器，組合獨立的 ScopeSelector 檢視。各級宿主獨立管理資料、搜尋和請求，僅選中身份參與級聯更新。

### [AgentConnect Agent 接入](./agent-connect)

Agent 接入檢視。頁籤、當前頁籤的條目與詳情正文都由宿主傳入；元件渲染列表與詳情，並上報切換與複製意圖。

### [圖示](./icons)

提供音訊、PDF、簡報、影片與文字文件五種檔案型別圖示，支援自定義圖片尺寸與無障礙描述。

公開包入口、樣式選擇與應用接入邊界見[快速開始](../guide/getting-started)。
