# FileTree 檔案樹

FileTree 把宿主提供的行渲染成可展開、可鍵盤操作的檔案樹。

## 何時使用

- 資料由宿主載入和管理（分頁、懶載入、許可權裁剪）時：把樹狀態展平成有序的行傳入，展開、選中和載入更多由宿主執行，元件在操作成功後通知。
- 需要自己決定搜尋介面、匯入入口和行尾操作時：元件只渲染並觸發回呼，不發起請求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 時，檔案樹已經內建，不需要單獨接入。

## 引入

```tsx
import { FileTree } from '@openviking/react/components/file-tree';
import '@openviking/react/components/file-tree/style.css';
```

## 程式碼演示

### 基礎用法

宿主自己維護展開集合和分頁狀態，把樹展平成 `FileTreeRow[]` 傳入，演示非同步載入、分頁、空目錄、內建目錄說明、行尾圖示和重新整理。展開 `resources` 下的 `archive` 和 `empty-notes` 檢視分頁與空目錄，選擇重新整理結果後點擊重新整理檢視成功和失敗狀態。

### FileTreeRow

`rows` 裡的每一行是下面五種型別之一，用 `kind` 區分。

| 取值          | 說明                                                                                | 型別                  |
| ------------- | ----------------------------------------------------------------------------------- | --------------------- |
| `'entry'`     | 目錄或檔案，每個節點一行                                                            | `FileTreeEntryRow`    |
| `'loading'`   | 目錄的子節點載入中，插在父節點下方，也可以不產出，改用條目行的 `busy`               | `FileTreeLoadingRow`  |
| `'load-more'` | 子節點分頁且還有下一頁時的「載入更多」行，一次性返回全部子節點的資料來源不需要        | `FileTreeLoadMoreRow` |
| `'error'`     | 子節點載入失敗，帶重試按鈕；`rows` 裡只有這一行且沒有 `parentId` 時表示整樹載入失敗 | `FileTreeErrorRow`    |
| `'empty'`     | 已展開但沒有子節點的目錄                                                            | `FileTreeEmptyRow`    |

## 注意

### 匯出

- 行、文案、控制代碼等型別和輔助函式從 `@openviking/react/components/file-tree` 匯出，包根入口只匯出 `FileTree` 和 `FileTreeProps`。
- `FileTree` 的型別是 `FileTreeComponent`，通過 `ref` 取得 `FileTreeHandle`，React 18 和 19 都支援。

### 行

- 樹狀態由宿主持有：展開、選中和子節點載入都在宿主，元件只渲染 `rows`。展開或選中發生後，更新 `expanded` 和 `selectedId` 再傳入。
- `rows` 是展平後的一維列表，按傳入順序渲染，縮排由 `depth` 決定，元件不檢查行之間的層級關係。子節點行及其狀態行緊跟在父節點之後，`depth` 為父節點加 1。
- 行是普通物件，傳入前可以自行排序、過濾或按許可權裁剪。
- `rootOrder="context"` 按 URI 首段把根目錄排成 `user → session → agent → resources`，接受單複數寫法（如 `users`、`agents`），其他目錄排在後面並保持相對順序。只有根層的目錄行參與排序，連同子樹一起移動，根層的檔案行和狀態行（如分頁行）保持原位置。

### 操作與通知

- `operations` 的方法返回 `Promise<void>`，完成表示成功，被 reject 表示失敗。成功後才觸發對應的 `on…` 回呼，失敗時不觸發。
- 省略某個方法，對應操作不可用：展開箭頭、「載入更多」、「重試」、搜尋和重新整理按鈕停用，點選行不會選中。省略 `on…` 回呼不影響操作執行。
- 同一操作（同一行的選中、展開、載入更多、重試，或搜尋、重新整理）尚未完成時，重複觸發會被忽略。

### 選中、鍵盤與許可權

- 點選目錄和點選檔案都呼叫 `operations.select`，宿主按 `row.type` 區分。點選展開箭頭只調用 `operations.toggleExpand`，不會選中。
- `renderDashboard` 返回的內容在行內，點選會冒泡到行並觸發選中。需要獨立的點選行為時呼叫 `event.stopPropagation()`，示例中的看板圖示就是這樣處理的。
- 鍵盤：上下方向鍵移動焦點，右鍵展開目錄，左鍵摺疊目錄，Enter 和空格選中。
- 樹使用 `role="tree"`，行使用 `role="treeitem"` 並輸出 `aria-level`（`depth` 加 1）、`aria-selected`、`aria-expanded` 和 `aria-disabled`，用 `aria-label` 給樹命名。
- 許可權狀態由宿主提供，元件不發鑑權請求：`disabled` 的行不能選中和展開，`selectable: false` 的行不能選中但可以展開，`access` 只在行尾顯示文字標記，不改變行為。

### 搜尋與重新整理

- 搜尋入口和重新整理按鈕預設顯示，`search`、`refresh` 傳 `false` 分別隱藏。兩者都隱藏時不渲染這一行，`slots.toolbar` 不受影響。
- 重新整理等待期間（`loading`、`refresh.loading` 或 `operations.refresh` 返回的 Promise 任一在進行），按鈕顯示載入態並停用，重複點選不會重複執行。`operations.refresh` 被 reject 後按鈕恢復，且不觸發 `onRefresh`。
- 重新整理按鈕懸停或聚焦時顯示提示，按 Esc 關閉。`labels.refresh` 同時是提示文案和按鈕的無障礙名稱。
- 搜尋入口的預設文案帶有 `⌘+K` 提示，元件不註冊這個快捷鍵，也不過濾行。搜尋介面、快捷鍵和結果處理由宿主通過 `operations.search` 接入。

### 目錄說明

- 元件按行 `uri` 的路徑結構判斷目錄語義，內建對應的說明和觸發行為文案，不需要宿主傳入。匹配只看路徑，忽略 `viking://` 字首、大小寫、查詢串和末尾斜槓，與 `type` 無關。
- 內建說明只覆蓋固定層級：`viking://resources` 匹配 `sharedResources`，`viking://resources/docs` 不匹配，更深的節點由宿主決定。
- 說明顯示在名稱後面。懸停行時在右側彈出浮層，內容是標題、說明、觸發行為和路徑。長期記憶下的九個鍵（`profile` 到 `experiences`）只在浮層顯示說明。
- 行上的 `description` 優先於內建說明，空字串表示不顯示。`labels.info` 按鍵覆蓋內建文案，空字串同樣表示不顯示，沒有覆蓋的鍵使用當前語言的內建文案。
- `uri` 沒有匹配任何鍵時，不顯示內建浮層。提供 `renderRowTooltip` 後，浮層內容完全由它決定。

```tsx
<FileTree
  rows={rows}
  labels={{
    info: {
      description: { userRoot: '當前使用者' },
      triggerBehavior: { memories: '提交會話時自動沉澱' },
      field: { description: '說明', triggerBehavior: '觸發行為', path: '路徑' },
    },
  }}
/>
```

### 定位行

- 每個行元素都帶有 `data-file-tree-row-id` 屬性，值為行的 `id`，屬性名以 `FILE_TREE_ROW_ATTRIBUTE` 匯出。頁面層可以據此實現一次性高亮或覆蓋層。
- `getRowAttributes(row)` 為行追加類名和屬性：`className`、`style` 與元件自身的合併，條目行的 `onClick`、`onKeyDown` 由元件接管。
- `ref` 提供 `getRowElement(id)` 和 `scrollToRow(id, options)`，例如在 [DirectoryTour](./directory-tour) 的 `locateTarget` 裡返回要定位的行元素。

```tsx
const treeRef = useRef<FileTreeHandle>(null);

<FileTree ref={treeRef} rows={rows} />;

treeRef.current?.scrollToRow('resources', { block: 'center' });
```

### 佈局

- 樹的根元素高度為 `100%`，內容在樹內部滾動，需要給外層容器設定高度。
- 行寬按內容撐開，名稱完整顯示，容器橫向滾動。層級很深時縮排同樣靠橫向滾動獲得空間。
- 說明文字最寬 200px，超出省略，避免長說明撐寬整行。
- `renderDashboard` 返回的內容緊跟在名稱和其他標記之後，要靠右對齊時給它設定 `margin-left: auto`，示例就是這樣做的。

## 主題變數

根元素的類名是 `ov-file-tree`，內部元素為 `ov-file-tree__<元素>`，例如 `ov-file-tree__row`。顏色優先讀取你在祖先元素上設定的 `--ov-ui-color-*`，沒有設定時使用庫的內建值，設定方法見[快速開始](../guide/getting-started)的主題一節；只調整檔案樹時覆蓋下面的變數。
