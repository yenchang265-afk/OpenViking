# Tui 命令控制台

可選 `locale: 'zh-CN' | 'en-US'` 覆蓋最近的模組或 Provider；均未配置時預設 `en-US`。已有 `labels` 可逐項覆蓋。業務內容仍由宿主提供。

命令控制台主體：當前命令記錄、結果、空態，以及帶建議和幫助的輸入區域。宿主提供命令目錄並負責請求、許可權、執行和會話；元件通過 `onSubmit` 上報提交意圖，通過 `onCopy` 通知複製完成。

檢視已實現命令記錄與七種結果變體、空態，以及帶補全和引數提示的受控輸入。業務命令目錄由宿主提供。

## 基礎用法

```tsx file="../../_demos/tui-basic.tsx" preview

```

示例自己維護記錄與輸入：傳送後追加等待中的記錄，再按命令對應的結果結構更新。所有命令均使用固定模擬資料，不會發送真實請求。可輸入 `ov compile`、`ov task list`、`ov session get session_demo` 或 `ov help`，分別檢視寫入、表格、狀態和幫助結果。

輸入區是整寬的無邊框編輯區域，帶頂部分隔線，編輯區域最小高度 80px，底部快捷鍵引導高 40px。聚焦時分隔線保持原色。內容最多自適應增高至三行，超出後滾動；底部依次顯示 `/ 全部指令`、`↑ 歷史指令`、`↵ 傳送`。↑/↓ 可回填當前記錄中的命令，Enter 提交，Shift+Enter 換行，不單獨渲染髮送按鈕。

輸入 `o` 時會以灰字提示 `v`，按 Tab 接受字首；也可直接按空格補成 `ov `。在 `ov ` 後按 Tab 開啟全部命令，繼續輸入字母可篩選候選並預覽剩餘文字，再按 Tab 接受行內提示或已選中的命令。普通輸入只顯示行內提示，`/` 和顯式 Tab 才展開列表；補全根據宿主的 `inputText` 推導。普通 Tab 始終保留輸入區焦點：無補全、輸入引數或游標位於中間時保持原值和頁面位置；Shift+Tab 可移出輸入區。灰字不會進入提交值。

輸入 `/`，或在 `ov ` 後按 Tab，都會展開未選中任何命令的候選列表；篩選或重新開啟時也清除選中狀態。斜槓發現同樣支援多詞名稱及別名，例如 `/session g`；進入引數階段前持續提供候選。未選擇時，↓ 從第一項開始，↑ 從最後一項開始。懸停或使用方向鍵選擇後，側邊才顯示示例與參數列。沒有關鍵字也未選擇候選時，Tab 不填入命令。橫向空間不足時，詳情與列表上下排列。Esc 或點選區域外可關閉浮層；不支援原生 Popover 的瀏覽器回退為內聯面板。

選中命令後，編輯區按宿主提供的 `inputText` 顯示灰色 CLI 字首和正文色加重的命令名，在其後用淺色直接提示位置引數；沒有位置引數時提示必填選項。開始填寫引數後，佔位提示收起，且不會寫入 `value` 或提交文本。完整詳情面板只在命令候選列表展開時展示。

輸入區與命令記錄統一使用灰色 CLI 字首、正文色加重的命令名、連結色資源 URI；連結僅在 hover 時顯示下劃線。命令記錄按同一份 `inputText` 顯示，引數原樣保留；時間單獨位於下一行並右對齊。複製和歷史回填使用相同字首，未匹配目錄的命令按原文顯示。

共用示例通過 `useLang()` 跟隨文件站語言，同時提供對應語言的命令描述、分組和結果。`locale="zh-CN"` 選擇中文介面文案，`locale` 可選並繼承上層語言；`labels` 可單獨覆蓋介面文案。命令和結果文案由宿主本地化。

## 空態與快捷命令

```tsx file="../../_demos/tui-empty.tsx" preview

```

此示例從空記錄開始，只傳 `quickCommands` 就得到內建空態：標題、說明和快捷命令列表。呼叫方從傳給 `commands` 的同一份目錄中選擇、排序 `quickCommands`，未命中的名稱跳過。點選快捷命令回填並聚焦輸入區，在輸入區補充引數並按 Enter 才提交；首次提交後，歡迎頁由模擬執行結果替換。

懸停快捷命令時，箭頭輕微後退、前進後回位，播放一次；啟用系統的減少動態效果設定時保持靜止。

不傳 `emptyState` 和 `quickCommands` 時不顯示任何空態內容。需要完全自定義時傳 `emptyState`，它替換整個內建空態。

## 元件邊界

Tui 只包含當前命令記錄與結果、空態，以及帶建議和幫助的命令輸入區。新建會話、歷史記錄面板、檢視與使用者切換、外層工具欄，由宿主通過獨立元件組合。

宿主處理會話和歷史操作後，更新 `records` 與 `value`。歷史結果複用同一套記錄檢視；Tui 不維護歷史列表、專門的歷史預覽狀態，也不提供外層工具欄或動作插槽。

宿主通過 `commands` 和可選的 `commandGroups` 提供目錄；Tui 負責篩選、高亮、鍵盤選擇、填入及引數幫助。接受補全通過 `onValueChange` 更新輸入；顯式提交觸發 `onSubmit`，由宿主執行並通過 `records` 回填狀態和結果。

命令名稱、別名、分組、說明、引數、選項和示例都是描述資料。新增命令沿用現有描述和結果型別時，只需更新宿主資料，無需釋出元件。宿主可以自行載入或更新服務端目錄，Tui 不取數。示例目錄位於 `docs/docs/_demos/tui-commands/`。

## 屬性

公開的 props 從同一子路徑以型別匯出，以原始碼為準：

```tsx
import type {
  TuiCommandDefinition,
  TuiCommandGroup,
  TuiLabels,
  TuiProps,
  TuiRecord,
  TuiRecordContent,
  TuiSearchResultItem,
} from '@openviking/react/components/tui';
```

下表說明已實現的行為。

| 屬性          | 型別                            | 預設值           | 說明                                                                                          |
| ------------- | ------------------------------- | ---------------- | --------------------------------------------------------------------------------------------- |
| records       | readonly TuiRecord[]            | 必填             | 當前展示的執行記錄，按提交順序排列；會話與歷史切換後由宿主更新。                              |
| value         | string                          | 必填             | 受控輸入值。                                                                                  |
| disabled      | boolean                         | false            | 停用命令輸入與提交，提示文案由 `labels.unavailableMessage` 提供。                             |
| emptyState    | ReactNode                       | —                | 無記錄時的空態節點，完全替換內建空態；傳 `null` 時同樣不顯示。                                |
| quickCommands | readonly string[]               | `[]`             | 內建空態展示的快捷命令名稱，按順序取自 `commands`，未命中的名稱跳過，重複名稱只保留首次出現。 |
| `locale`      | `'zh-CN' \| 'en-US'`            | 繼承上層 / en-US | 選擇內建中英文文案。                                                                          |
| commands      | readonly TuiCommandDefinition[] | `[]`             | 宿主命令目錄，用於補全、幫助及等待骨架。                                                      |
| commandGroups | readonly TuiCommandGroup[]      | `[]`             | 宿主分組名稱和順序；未宣告的組按目錄順序追加。                                                |
| labels        | TuiLabels                       | —                | 統一的介面文案與引導提示。                                                                    |
| onValueChange | (value: string) => void         | —                | 上報輸入變化，包含接受的命令和示例；行內佔位不改變輸入值，也不提交。省略時輸入框只讀。        |
| onSubmit      | (command: string) => void       | —                | 顯式提交時上報意圖，由宿主執行；省略時不能提交。                                              |
| onOpenUri     | (uri: string) => void           | —                | 連結啟用時接收原始 URI，由宿主負責開啟資源。                                                  |
| onCopy        | (text: string) => void          | —                | 複製成功後觸發，引數為已複製的文本；失敗時不觸發。省略回撥不影響複製。                        |

`onSubmit` 上報提交的文本，不等待執行結果。宿主負責傳送、許可權和執行，並更新等待、成功或失敗的記錄；已有 `pending` 記錄不阻止後續提交。

記錄更新僅在讀者接近底部時跟隨輸出；向上滾動會保留閱讀位置，主動提交後恢復跟隨。資源表格始終保留每項的名稱、原生 URI 連結和元資訊，沒有明細的項也會顯示。

未提供 `onValueChange` 時，輸入、提交和幫助命令填入均為只讀；`disabled` 同樣禁止這些操作。結構化資源連結僅接受 `viking://`、`https://` 和 `http://`，不支援的目標顯示為純文本。搜尋摘要、摘錄、描述、元資訊和寫入結果訊息等正文的 URI 連結排除句末標點；資源標識和結構化原始值使用字面值匹配。命令、編輯器和程式碼中的 URI 以空白和引號等引用分隔符為邊界，保留檔名中的逗號、分號及括號。JSON 縮排保留數字等原始值，不通過反序列化後的值重寫輸出。

`emptyState` 是完全自定義空態的入口：傳節點時替換整個內建空態，傳 `null` 時不顯示空態。省略時由內建空態按 `quickCommands` 渲染標題、說明與快捷命令列表；沒有可用快捷命令時不顯示任何內容。

### 命令描述

`TuiCommandDefinition` 包含 `name`、`description`、`usage`，以及可選的 `inputText`、`summary`、`aliases`、`group`、`params`、`options`、`examples` 和 `skeleton`。引數使用 `label`，選項使用 `token`，兩者均支援 `description`、`required` 和 `defaultValue`。`inputText` 指定接受命令時填入的字首，預設 `name`；demo 提供 `ov read` 等 CLI 字首。`required` 預設 `false`，省略 `defaultValue` 時展示破折號。分組包含 `key` 和 `label`。示例接受字串或 `{ value, label? }`，選擇後僅填入 `value`；宿主可展示帶 CLI 字首的示例，同時填入斜槓命令。

省略 `commands` 時仍可輸入和提交文本，但不展示命令候選或引數幫助。元件不翻譯宿主描述，也不校驗命令許可權。

### 結果內容

所有結果共用命令標題與帶無障礙名稱的成功、失敗或載入圖示。匹配到宿主命令時，標題使用其 `inputText`，不包含引數；正文中的同名命令標題不會重複顯示。寫入結果逐行使用獨立底色，狀態結果顯示帶底色的鍵值行，資源預覽有獨立的正文容器；JSON 與 Markdown 程式碼塊共用可複製的程式碼檢視。Markdown 有序列表保留可見的原生編號，包含非預設起始序號。命令執行成功與返回任務中的 `pending` 狀態分別表達。

程式碼塊使用純圖示複製按鈕，懸停或鍵盤聚焦時提示“複製”，成功後圖標短暫變為勾選，提示切換為“複製成功”；可用 `labels.copy`、`labels.copied` 替換文案。複製失敗不顯示成功反饋，也不觸發 `onCopy`。

空結果文案由 `labels.noResult` 配置；幫助標題和引導由 `labels.availableCommands`、`labels.helpHint` 配置。

`TuiRecordContent` 包含一種通用文本與六種結構化結果：

| variant          | 資料            | 說明                         |
| ---------------- | --------------- | ---------------------------- |
| text             | text, format?   | 通用輸出，格式預設為 plain。 |
| search-list      | items, summary? | 檢索結果與彙總。             |
| resource-preview | title, content  | 資源正文預覽。               |
| resource-tree    | items, title?   | 資源條目與明細。             |
| status           | rows, title?    | 鍵值狀態行。                 |
| write-result     | lines, title?   | 寫入操作結果。               |
| command-help     | sections        | 按分組展示可用命令。         |

`text.format` 支援 `plain` 和 `markdown`，預設為 `plain`。JSON 格式化為字串後通過 `text` 展示。失敗通過 `TuiRecord.status: 'error'` 表達，錯誤正文使用文本結果，不單獨定義錯誤內容變體。

每種變體都有對應檢視：純文本或 Markdown（JSON 自動縮排）、帶分數詳情的檢索行、資源預覽、可按列對齊並分頁的資源表、狀態行、寫入結果行與分組命令幫助。輸入區、命令氣泡、Markdown 和結構化結果字串中的資源 URI 連結共用 `onOpenUri`。自定義 ReactNode 內部的連結由宿主處理。點選輸入區連結不會改變或提交命令；Shift+Tab 可聚焦連結，再按 Enter 啟用。CLI 輸出到這些變體的轉換仍由宿主負責。

### 文案與引導提示

通用介面文案跟隨 `locale`，可通過 `labels` 逐項覆蓋。命令名稱、分組、說明和引數幫助來自宿主描述。

| 屬性                      | 型別   | 說明                                                          |
| ------------------------- | ------ | ------------------------------------------------------------- |
| labels.unavailableMessage | string | `disabled` 為 `true` 時的不可用提示；僅修改文案不會停用元件。 |
| labels.pending            | string | 等待中的狀態文本。                                            |
| labels.emptyTitle         | string | 內建空態的標題。                                              |
| labels.emptyDescription   | string | 內建空態的說明。                                              |
| labels.quickStart         | string | 快捷命令列表上方的引導文案。                                  |
| labels.allCommands        | string | `/` 全部指令的快捷鍵說明。                                    |
| labels.historyCommands    | string | `↑` 歷史指令的快捷鍵說明，回填範圍為當前 records。            |
| labels.send               | string | `↵` 傳送的快捷鍵說明。                                        |

`disabled` 預設為 `false`。設為 `true` 時停用命令輸入與提交，提示內容由 `labels.unavailableMessage` 定製。

引數幫助標題、表頭、必填文案和分頁提示也可通過 `labels.parameters`、`examples`、`noParameters`、`parameter`、`required`、`description`、`defaultValue`、`yes`、`no`、`loadMore` 和 `resource`（資源表格的名稱列）覆蓋。

### 檢索結果詳情

`TuiSearchResultItem` 支援以下可選展示欄位：

| 屬性         | 型別      | 說明                                                                   |
| ------------ | --------- | ---------------------------------------------------------------------- |
| levelLabel   | string    | 標題旁的內容層級標籤。                                                 |
| typeLabel    | string    | 分數旁的結果型別標籤。                                                 |
| scoreLabel   | string    | 宿主格式化後的分數文案。                                               |
| scoreDetails | ReactNode | 懸停或鍵盤聚焦分數時展示的宿主詳情內容，僅在提供 `scoreLabel` 時顯示。 |

### 記錄時間

宿主傳入 Unix 毫秒時間戳 `createdAtMs`，由元件格式化：不足 1 分鐘顯示“剛剛”，不足 1 小時顯示整分鐘數，不足 24 小時顯示整小時數；24 小時及以上顯示瀏覽器本地時區的 `YYYY-MM-DD HH:mm`。未來時間戳顯示“剛剛”。

| 欄位        | 型別   | 預設值 | 說明                                                                    |
| ----------- | ------ | ------ | ----------------------------------------------------------------------- |
| createdAtMs | number | —      | 優先用於元件內格式化；非有限數或超出日期範圍時回退到 `createdAt`。      |
| createdAt   | string | —      | 無有效時間戳時使用的可選展示文案；不會把 `10:24` 這類字串解析為日期。 |

服務端首屏和 hydration 使用 `createdAt`，未提供時暫不展示時間；客戶端接管後按客戶端時鐘格式化時間戳。時間隨渲染重新計算，不設定獨立定時重新整理。`labels.justNow`、`labels.formatMinutesAgo(minutes)` 和 `labels.formatHoursAgo(hours)` 可覆蓋時間文案，預設跟隨 `locale`。兩個示例均傳入時間戳，執行結果更新時保留最初的提交時間。

### 等待中的記錄

`TuiRecord` 為 `pending` 時，元件按命令名或別名匹配宿主目錄，使用描述的可選 `skeleton`；未提供或未識別時使用通用骨架。等待時可省略 `content`。

元件和樣式的匯入方式：

```tsx
import { Tui } from '@openviking/react/components/tui';
import '@openviking/react/components/tui/style.css';
```

## 實現範圍

元件渲染宿主資料並處理本地輸入互動。請求、響應轉換、執行、持久化、許可權和網路連線由宿主負責。
