# CommandConsole 命令控制台

終端風格的命令記錄與輸入檢視：展示命令記錄及其結果，輸入區提供命令補全和引數幫助。

## 何時使用

- 需要命令列式的輸入和結果展示，並自己決定有哪些命令、如何執行時：元件不發起請求，也不讀寫本地儲存，不需要 `OpenVikingProvider`。
- 需要用同一套檢視展示文本、檢索結果、資源預覽、狀態和寫入結果等不同型別的命令輸出時。
- 使用 [Console](../modules/console) 時，命令模式已經內建 CommandConsole，不需要單獨接入。

## 引入

```tsx
import { CommandConsole } from '@openviking/react/components/command-console';
import '@openviking/react/components/command-console/style.css';
```

## 程式碼演示

### 基礎用法

演示帶多種結果型別的命令記錄和帶補全的輸入區。輸入 `/` 檢視候選，提交 `ov compile --compile-name demo-wiki`、`ov task list`、`ov session get session_demo` 或 `ov help`，分別得到寫入結果、表格、狀態和命令幫助。

```tsx file="../../_demos/command-console-basic.tsx" preview

```

示例使用固定的模擬資料：提交後先追加一條執行中的記錄，稍後替換為結果，不傳送請求；點選資源連結只彈出提示。

### 空態與快捷命令

沒有記錄時顯示快捷入口，點選只把命令填入輸入區，按 Enter 才提交，提交後空態被記錄取代。每行顯示 `summary`，省略時回退到 `description`；提供了 `summary`，或說明被單行省略截斷時，懸停該行顯示完整的 `description`。

```tsx file="../../_demos/command-console-empty.tsx" preview

```

示例的快捷入口都填入完整命令，只有 `compile` 例外：它只填入 `ov compile `，需要繼續輸入 `--compile-name <name>`。

## API

### CommandConsole

| 引數             | 說明                                                                                       | 型別                                                                  | 預設值                   |
| ---------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- | ------------------------ |
| records          | 要展示的命令記錄，按提交順序排列                                                           | `readonly CommandConsoleRecord[]`                                     | 必填                     |
| value            | 輸入區的文本，受控                                                                         | `string`                                                              | 必填                     |
| disabled         | 停用輸入和提交，並在輸入區下方顯示 `labels.unavailableMessage`                             | `boolean`                                                             | `false`                  |
| emptyState       | 沒有記錄時顯示的內容，替換內建空態；傳 `null` 時不顯示空態                                 | `ReactNode`                                                           | -                        |
| quickCommands    | 內建空態裡的快捷入口，沒有可用入口時內建空態不顯示內容                                     | `readonly CommandConsoleQuickCommand[]`                               | -                        |
| commands         | 命令目錄，用於補全、引數幫助和執行中記錄的骨架；省略時仍可輸入和提交，但沒有候選和引數幫助 | `readonly CommandConsoleCommandDefinition[]`                          | `[]`                     |
| commandGroups    | 候選列表的分組名稱和順序，沒有宣告的分組按出現順序排在後面                                 | `readonly CommandConsoleCommandGroup[]`                               | `[]`                     |
| onValueChange    | 輸入變化時觸發，包括接受補全和示例；省略時輸入區只讀                                       | `(value: string) => void`                                             | -                        |
| onSubmit         | 按 Enter 提交時觸發，引數是去掉首尾空白的命令文本；省略時不能提交                          | `(command: string) => void`                                           | -                        |
| onOpenUri        | 點選資源連結時觸發，引數是連結地址；省略時連結按 `href` 原生跳轉                           | `(uri: string) => void`                                               | -                        |
| onCopy           | 複製成功後觸發，引數是已複製的文本                                                         | `(text: string) => void`                                              | -                        |
| slots            | 替換渲染異常的展示內容，見[錯誤展示插槽](../guide/getting-started#自定義錯誤展示)          | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }` | -                        |
| labels           | 覆蓋介面文案，欄位見 [CommandConsoleLabels](#commandconsolelabels)                         | `CommandConsoleLabels`                                                | -                        |
| locale           | 介面語言，規則見[國際化](../guide/i18n)                                                    | `'zh-CN' \| 'en-US'`                                                  | 繼承上級，預設 `'en-US'` |
| className、style | 外觀與佈局，其餘 HTML 屬性透傳到根元素                                                     | HTML 屬性                                                             | -                        |

### CommandConsoleRecord

| 引數        | 說明                                                                                            | 型別                                               | 預設值 |
| ----------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------ |
| id          | 記錄的唯一標識                                                                                  | `string`                                           | 必填   |
| command     | 提交的命令文本，顯示在結果上方；匹配到 `commands` 中的命令時，命令名部分按它的 `inputText` 顯示 | `string`                                           | 必填   |
| status      | 執行狀態，隻影響這一條記錄；`'pending'` 且尚無後臺任務結果時顯示載入骨架，其餘狀態顯示結果      | `'pending' \| 'success' \| 'error' \| 'cancelled'` | 必填   |
| tasks       | 後臺任務快照，元件僅展示傳入的狀態                                                              | `readonly CommandConsoleTask[]`                    | -      |
| content     | 執行結果；帶後臺任務的記錄在執行中也顯示它，省略時按狀態顯示骨架或空結果                        | `CommandConsoleRecordContent`                      | -      |
| createdAtMs | 提交時間，Unix 毫秒時間戳，顯示在命令下方                                                       | `number`                                           | -      |
| createdAt   | 沒有有效 `createdAtMs` 時顯示的文本，也用於服務端渲染；不會被解析為日期                         | `string`                                           | -      |

`CommandConsoleTask` 的欄位與 [ConsoleTaskSnapshot](../modules/console#consoletasksnapshot) 一致。

### CommandConsoleRecordContent

執行結果的聯合型別，通過 `variant` 區分。

| variant              | 說明                                          | 型別                                   |
| -------------------- | --------------------------------------------- | -------------------------------------- |
| `'text'`             | 純文本或 Markdown，也用來顯示 JSON 和錯誤資訊 | `CommandConsoleTextContent`            |
| `'search-list'`      | 檢索結果列表                                  | `CommandConsoleSearchListContent`      |
| `'resource-preview'` | 單個資源的正文預覽                            | `CommandConsoleResourcePreviewContent` |
| `'resource-tree'`    | 資源條目列表，帶明細時顯示為表格              | `CommandConsoleResourceTreeContent`    |
| `'status'`           | 鍵值狀態行                                    | `CommandConsoleStatusContent`          |
| `'write-result'`     | 寫入類命令的結果行                            | `CommandConsoleWriteResultContent`     |
| `'command-help'`     | 按分組列出的可用命令                          | `CommandConsoleCommandHelpContent`     |

### CommandConsoleTextContent

| 引數    | 說明                                                                                                 | 型別                    | 預設值    |
| ------- | ---------------------------------------------------------------------------------------------------- | ----------------------- | --------- |
| variant | 結果型別，固定為 `'text'`                                                                            | `'text'`                | 必填      |

| format  | 文本格式：`'plain'` 按原文顯示，`'markdown'` 渲染為 Markdown（支援 GFM）                             | `'plain' \| 'markdown'` | `'plain'` |

### CommandConsoleCommandDefinition

## 注意

- `onSubmit` 只上報命令文本，由宿主執行：追加一條 `status: 'pending'` 的記錄，完成後更新為 `'success'` 或 `'error'`。執行中的記錄不阻止繼續提交，需要限制時傳 `disabled`。
- 失敗時把 `status` 設為 `'error'`，錯誤資訊使用 `text` 結果。元件不解析命令輸出，宿主需要把執行結果轉換成 `CommandConsoleRecordContent`。
- `'success'` 只表示命令本身執行成功，不代表它啟動的任務已經完成。
- 新建會話、歷史記錄面板和外層工具欄由宿主自行組合，元件沒有對應的插槽。宿主切換會話或歷史後，更新 `records` 和 `value`。
- Enter 提交，Shift+Enter 換行，元件不提供傳送按鈕。
- ↑、↓ 回填 `records` 裡的命令，候選列表展開時改為選擇候選。Tab 始終留在輸入區，Shift+Tab 移出。
- 輸入命令名時，剩餘部分以灰字提示，按 Tab 接受，灰字不會寫入 `value`，也不會被提交。輸入 `/`，或在命令字首後按 Tab，展開候選列表，用 ↑、↓ 選擇，Tab 或 Enter 填入，Esc 關閉。
- 懸停或選中候選命令時，列表旁顯示它的用法、示例和參數列；接受命令後，輸入區在命令名後以淺色提示位置引數，開始輸入引數後提示消失。
- 記錄更新時，只有讀者接近底部才會自動滾到最新；向上滾動會保留閱讀位置，提交命令後恢復跟隨。
- 根元素高度為 `100%`，記錄區在內部滾動，輸入區固定在底部，需要給父容器設定確定的高度。
- 輸入區、命令記錄和結果文本里的 `viking://`、`http://`、`https://` 地址會自動成為連結，點選連結不會提交命令；`onOpenUri` 收到的是連結地址。
- 說明文字裡的連結不含句末標點，命令、程式碼塊和資源值裡的連結保留檔名中的標點。結構化結果的 `uri` 只接受這三種協議，其他顯示為純文本。
- Markdown 文本里的 `http(s)` 連結和地址在新標籤頁開啟，不觸發 `onOpenUri`；`viking://` 的會觸發。
- JSON 和 Markdown 程式碼塊帶複製按鈕，複製成功後觸發 `onCopy`；瀏覽器拒絕寫入剪貼簿時不顯示成功提示，也不觸發 `onCopy`。
- `createdAtMs` 不足 1 分鐘顯示「剛剛」，不足 1 小時顯示整分鐘數，不足 24 小時顯示整小時數，之後顯示本地時區的 `YYYY-MM-DD HH:mm`；晚於當前時間的時間戳顯示「剛剛」。文案可用 `labels.justNow`、`labels.formatMinutesAgo`、`labels.formatHoursAgo` 覆蓋。
- 服務端渲染和 hydration 首屏使用 `createdAt`，沒有則不顯示時間；客戶端接管後改用 `createdAtMs`。時間只在渲染時重新計算，不會定時重新整理。
- 顏色取自 `--ov-ui-color-*` 主題變數，暗色模式跟隨 `<html>` 上的 `.dark` 類，詳見[快速開始](../guide/getting-started)。
- 型別從 `@openviking/react/components/command-console` 匯出，包根入口只匯出元件和 `CommandConsoleProps`。
