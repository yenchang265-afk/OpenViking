# ScopeSwitcher 作用域選擇

由多級獨立選擇器組成的作用域麵包屑：`ScopeSwitcher` 負責排列，每一級（例如庫、資料空間、使用者）用一個 `ScopeSelector` 展示當前值並切換。

## 何時使用

- 在頁面頭部用麵包屑展示並切換庫、資料空間、使用者等多級作用域。
- 需要自己控制每一級的請求、選項、搜尋和分頁時：元件只負責展示，不發起請求，也不需要 `OpenVikingProvider`。
- 只想傳入三個載入函式完成「庫 → 資料空間 → 使用者」級聯時，使用 [ScopeCascade](../modules/scope-cascade)，它已內建 ScopeSwitcher。

## 引入

```tsx
import {
  ScopeSwitcher,
  ScopeSelector,
} from '@openviking/react/components/scope-switcher';
import '@openviking/react/components/scope-switcher/style.css';
```

## API

### ScopeSwitcher

| 引數             | 說明                                                                                        | 型別                 | 預設值                   |
| ---------------- | ------------------------------------------------------------------------------------------- | -------------------- | ------------------------ |
| children         | 各級的 `ScopeSelector`，從左到右排列，相鄰兩級之間自動繪製分隔符 `/`                        | `ReactNode`          | -                        |
| locale           | 其中所有 `ScopeSelector` 的介面語言，規則見[國際化](../guide/i18n)；同時寫入根節點的 `lang` | `'zh-CN' \| 'en-US'` | 繼承上級，預設 `'en-US'` |
| className、style | 外觀與佈局，其餘 HTML 屬性透傳到根元素                                                      | HTML 屬性            | -                        |

### ScopeSelector

| 引數     | 說明                                                                                    | 型別                      | 預設值                   |
| -------- | --------------------------------------------------------------------------------------- | ------------------------- | ------------------------ |
| kind     | 層級形態：`'fixed'` 只顯示當前值，不可點選；`'selectable'` 顯示可展開的觸發器和下拉麵板 | `'fixed' \| 'selectable'` | 必填                     |
| identity | 層級的標識、無障礙名稱和末尾標記                                                        | `ScopeSwitcherIdentity`   | 必填                     |
| trigger  | 觸發器上顯示的文本和圖示；`fixed` 層級沒有 `data`，需要在這裡提供 `label`               | `ScopeSwitcherTrigger`    | -                        |
| data     | 選項和當前選中項，`fixed` 層級不接收                                                    | `ScopeSwitcherData`       | `selectable` 時必填      |
| state    | 載入、錯誤、停用、展開和搜尋詞等互動狀態，僅 `selectable` 接收                          | `ScopeSwitcherState`      | -                        |
| actions  | 選擇、展開、搜尋和滾動的回呼，僅 `selectable` 接收                                      | `ScopeSwitcherActions`    | -                        |
| slots    | 替換面板、選項行、空態和錯誤態的內容，僅 `selectable` 接收                              | `ScopeSwitcherSlots`      | -                        |
| labels   | 覆蓋介面文案                                                                            | `ScopeSwitcherLabels`     | -                        |
| locale   | 介面語言，規則見[國際化](../guide/i18n)                                                 | `'zh-CN' \| 'en-US'`      | 繼承上級，預設 `'en-US'` |

`ScopeSelectorProps` 是 `ScopeSelectorFixedProps` 與 `ScopeSelectorSelectableProps` 的聯合型別，兩者共有的屬性定義在 `ScopeSelectorBaseProps` 中。

### ScopeSwitcherIdentity

| 引數      | 說明                                                                                              | 型別        | 預設值 |
| --------- | ------------------------------------------------------------------------------------------------- | ----------- | ------ |
| key       | 層級的穩定標識，例如 `'library'`、`'space'`、`'user'`，供宿主區分層級，元件不讀取它               | `string`    | 必填   |
| ariaLabel | 觸發器和麵板的無障礙名稱，例如「切換庫」；不傳時觸發器沒有 `aria-label`，面板以觸發器上的文本命名 | `string`    | -      |
| tag       | 觸發器末尾的標記，例如套餐名                                                                      | `ReactNode` | -      |

### ScopeSwitcherTrigger

| 引數  | 說明                                                                                                                                 | 型別        | 預設值 |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------- | ------ |
| label | 觸發器上顯示的當前值；不傳時取 `data.options` 裡 `selectedId` 對應項的 `label`，都沒有時為空。當前值不在已載入的選項裡時，由宿主提供 | `string`    | -      |
| icon  | 觸發器上的圖示或頭像；不傳時使用選中項的 `icon`                                                                                      | `ReactNode` | -      |

### ScopeSwitcherData

| 引數           | 說明                                                                                       | 型別                             | 預設值           |
| -------------- | ------------------------------------------------------------------------------------------ | -------------------------------- | ---------------- |
| options        | 該層級的完整選項，按給定順序渲染；用來判斷當前選中值是否仍然有效，因此不要只放當前搜尋結果 | `readonly ScopeSwitcherOption[]` | 必填             |
| visibleOptions | 面板裡實際顯示的選項；搜尋過濾和分頁追加走這裡，不影響選中值的有效性判斷                   | `readonly ScopeSwitcherOption[]` | `options`        |
| selectedId     | 當前選中項的 `id`，未選擇時傳 `''`                                                         | `string`                         | 必填             |
| total          | 該層級的總條數，用於判斷是否顯示搜尋框                                                     | `number`                         | `options` 的條數 |

### ScopeSwitcherOption

| 引數        | 說明                                       | 型別        | 預設值  |
| ----------- | ------------------------------------------ | ----------- | ------- |
| id          | 選項的唯一標識                             | `string`    | 必填    |
| label       | 選項文本，搜尋命中的片段會高亮             | `string`    | 必填    |
| icon        | 行首圖示，例如庫、資料空間或使用者的頭像     | `ReactNode` | -       |
| description | 顯示在文本下方的次要說明，例如套餐或地址   | `string`    | -       |
| disabled    | 停用該選項：置灰顯示，不響應點選和鍵盤選擇 | `boolean`   | `false` |

### ScopeSwitcherState

| 引數          | 說明                                                                                          | 型別      | 預設值  |
| ------------- | --------------------------------------------------------------------------------------------- | --------- | ------- |
| loading       | 選項正在首次載入：面板顯示載入文案，不顯示列表                                                | `boolean` | `false` |
| error         | 選項載入失敗：面板顯示 `slots.errorFallback`，沒有時顯示 `labels.error`                       | `boolean` | `false` |
| busy          | 該層級有變更正在進行，例如正在切換資料空間：停用整個列表，避免併發選擇                        | `boolean` | `false` |
| disabled      | 該層級暫時不可切換：觸發器不響應點選，面板不展開                                              | `boolean` | `false` |
| visible       | 面板是否展開；提供後為受控模式，需要在 `actions.onVisibleChange` 裡寫回，不傳時由本級自行維護 | `boolean` | -       |
| searchKeyword | 當前搜尋詞，由宿主儲存；選項文本中命中的片段高亮，非空時即使選項不超過 10 條也會顯示搜尋框    | `string`  | `''`    |

### ScopeSwitcherActions

| 引數                  | 說明                                               | 型別                                            | 預設值 |
| --------------------- | -------------------------------------------------- | ----------------------------------------------- | ------ |
| onSelect              | 選中某一項時觸發；元件先關閉面板，選中值由宿主更新 | `(option: ScopeSwitcherOption) => void`         | -      |
| onVisibleChange       | 面板展開或關閉時觸發，引數為變化後的狀態           | `(visible: boolean) => void`                    | -      |
| onSearchKeywordChange | 搜尋詞變化時觸發；提供後才會顯示搜尋框             | `(keyword: string) => void`                     | -      |
| onScroll              | 選項列表滾動時觸發，宿主據此載入下一頁             | `(metrics: ScopeSwitcherScrollMetrics) => void` | -      |

### ScopeSwitcherSlots

| 引數          | 說明                                                                                         | 型別                                                             | 預設值                                        |
| ------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------- |
| renderPanel   | 接管面板內容：`search` 和 `list` 是元件渲染好的搜尋框和列表，標題、操作和底部入口由宿主排布  | `(panel: ScopeSwitcherPanelContent) => ReactNode`                | 只渲染 `search` 和 `list`                     |
| renderOption  | 在預設行內容的基礎上追加或替換，例如行尾的「更多」選單；行的點選、選中和鍵盤互動仍由元件處理 | `(content: ReactNode, option: ScopeSwitcherOption) => ReactNode` | 預設行內容                                    |
| emptyFallback | 沒有選項時替代列表顯示的內容                                                                 | `ReactNode`                                                      | `labels.empty`，有搜尋詞時為 `labels.noMatch` |
| errorFallback | 載入失敗時替代列表顯示的內容，例如帶重試入口                                                 | `ReactNode`                                                      | `labels.error`                                |

### ScopeSwitcherPanelContent

`renderPanel` 的引數。

| 引數   | 說明                                 | 型別        | 預設值 |
| ------ | ------------------------------------ | ----------- | ------ |
| search | 搜尋框；搜尋框不顯示時為空節點       | `ReactNode` | -      |
| list   | 選項列表，以及載入、空、失敗三種狀態 | `ReactNode` | -      |

### ScopeSwitcherScrollMetrics

`onScroll` 的引數。

| 引數         | 說明             | 型別     | 預設值 |
| ------------ | ---------------- | -------- | ------ |
| scrollTop    | 列表已滾動的距離 | `number` | -      |
| scrollHeight | 列表內容的總高度 | `number` | -      |
| clientHeight | 列表的可視高度   | `number` | -      |

### ScopeSwitcherLabels

預設值依次為 `zh-CN`、`en-US` 的內建文案。

| 引數              | 說明                                                        | 型別     | 預設值                                        |
| ----------------- | ----------------------------------------------------------- | -------- | --------------------------------------------- |
| loading           | 載入提示                                                    | `string` | `'載入中…'` / `'Loading…'`                    |
| searchPlaceholder | 搜尋框內的提示文字，同時是它的無障礙名稱                    | `string` | `'搜尋'` / `'Search'`                         |
| empty             | 沒有選項時的提示                                            | `string` | `'暫無選項'` / `'No options'`                 |
| noMatch           | 有搜尋詞但沒有命中時的提示；只設置了 `empty` 時沿用 `empty` | `string` | `'沒有匹配項'` / `'No matches'`               |
| error             | 載入失敗時的提示                                            | `string` | `'選項載入失敗'` / `'Unable to load options'` |

## 注意

- `ScopeSwitcher` 只負責佈局和語言，不儲存選中值。每一級的選項、選中值、搜尋詞和請求由宿主傳給對應的 `ScopeSelector`。
- 相鄰層級之間的分隔符 `/` 由樣式繪製，因此 `ScopeSelector` 要直接作為 `ScopeSwitcher` 的子節點；自定義的層級元件直接返回 `ScopeSelector`，不要再包一層 DOM。
- 固定層級和可切換層級可以混用，不需要的層級直接省略。
- 選中值由宿主歸一化：`ScopeSelector` 嚴格按 `data.selectedId` 渲染。`selectedId` 為空或不在 `options` 裡時沒有任何一行顯示為選中，命中停用項時仍顯示為選中；元件不會改寫選中值，也不會呼叫 `onSelect`。
- 資料到達後，宿主檢查 `selectedId` 是否仍在 `options` 裡（只被搜尋過濾出 `visibleOptions` 不算失效），無效則改選第一個可選項，並把結果寫回 URL 和請求引數。[ScopeCascade](../modules/scope-cascade) 已內建這一步。
- 上級的選中項變化後，給下級層級的宿主元件設定包含上級 id 的 `key`，下級重新掛載，舊的選項、搜尋詞、錯誤和展開狀態隨之清空。
- 展開狀態預設由各級自己維護，選擇後面板關閉。提供 `state.visible` 後改為受控，宿主在 `actions.onVisibleChange` 裡寫回；選擇時元件先請求關閉再呼叫 `onSelect`，宿主可以等非同步操作完成後再關閉面板。
- 搜尋框在兩個條件同時滿足時顯示：提供了 `actions.onSearchKeywordChange`，並且 `options`、`visibleOptions`、`total` 中最大的條數超過 10，或搜尋詞非空。選項的過濾由宿主完成，元件高亮命中的片段，不區分大小寫。
- 搜尋框的顯示閾值 10 以常量 `SCOPE_SWITCHER_SEARCH_THRESHOLD` 匯出，不能通過屬性修改。
- 鍵盤：在觸發器上按 ArrowDown 或 ArrowUp 展開面板；在選項行上，方向鍵迴圈移動焦點，Home、End 跳到首尾，Enter 或空格選擇，Escape 關閉面板並把焦點還給觸發器。點選面板外部或焦點離開選擇器時，面板同樣關閉。
- 面板展開後，焦點先落在搜尋框，沒有搜尋框時落在選中項，沒有選中項時落在第一個可選項。選擇後焦點回到觸發器，焦點已移到別處時不搶回。
- 停用選項，以及 `busy` 時的全部選項，不能選擇，方向鍵也會跳過它們。`renderOption` 裡內嵌的按鈕、連結和輸入框不會觸發行選擇。
- 觸發器帶有 `aria-haspopup="dialog"` 和 `aria-expanded`，面板是 `dialog`，列表是 `listbox`，選項行是帶 `aria-selected` 的 `option`。
- 圖示由宿主通過 `trigger.icon` 和 `option.icon` 傳入，元件不內建層級圖示。預設圖示可以從 `@openviking/react/icons` 取 `LibraryIcon`、`SpaceIcon`、`UserIcon`；ScopeCascade 會給適配函式沒有返回 `icon` 的選項自動補上這三個。
- 整行固定 32px 高，不換行；空間不足時各層級收縮、文本省略，單級觸發器最寬 260px。
- 視口寬度不超過 600px 時，面板改為貼底的整寬麵板；更寬時，最後一級的面板右對齊展開。
- 包根入口匯出 `ScopeSwitcher`、`ScopeSelector`、`ScopeSwitcherProps` 和 `ScopeSelectorProps`；其餘型別和 `SCOPE_SWITCHER_SEARCH_THRESHOLD` 從 `@openviking/react/components/scope-switcher` 匯入。

## 主題變數

變數宣告在 `.ov-scope-switcher` 上，通過 `ScopeSwitcher` 的 `style` 或自己的 CSS 覆蓋其中任意一條，設定在祖先節點上不會生效。共用的顏色取自 `--ov-ui-color-*`，規則見[快速開始](../guide/getting-started)，在祖先節點上設定即可覆蓋。

| 變數                                        | 說明                                                               | 預設值                        |
| ------------------------------------------- | ------------------------------------------------------------------ | ----------------------------- |
| `--ov-ui-scope-switcher-icon`               | 觸發器圖示和展開箭頭的顏色                                         | `--ov-ui-color-text-2`        |
| `--ov-ui-scope-switcher-option-icon`        | 選項行首圖示的顏色                                                 | `--ov-ui-scope-switcher-icon` |
| `--ov-ui-scope-switcher-option-icon-size`   | 選項行首圖示底槽的尺寸                                             | `24px`                        |
| `--ov-ui-scope-switcher-option-icon-radius` | 選項行首圖示底槽的圓角，渲染圓形頭像時設為 `50%`                   | `12px`                        |
| `--ov-ui-scope-switcher-row-hover`          | 選項行懸停時的底色                                                 | `--ov-ui-color-fill-hover`    |
| `--ov-ui-scope-switcher-tag-background`     | `identity.tag` 的底色                                              | `--ov-ui-color-bg-5`          |
| `--ov-ui-scope-switcher-tag-text`           | `identity.tag` 的文字色                                            | `--ov-ui-color-text-2`        |
| `--ov-ui-scope-switcher-panel-width`        | 下拉麵板的寬度                                                     | `272px`                       |
| `--ov-ui-scope-switcher-option-height`      | 選項行的最小高度                                                   | `44px`                        |
| `--ov-ui-scope-switcher-option-gap`         | 相鄰選項行的間距                                                   | `2px`                         |
| `--ov-ui-scope-switcher-list-max-height`    | 選項列表的最大高度，超出後在列表內滾動                             | `288px`                       |
| `--ov-ui-scope-switcher-panel-max-height`   | 面板的最大高度，另受視口高度限制；`renderPanel` 接管內容時同樣適用 | 列表最大高度加 `54px`         |
