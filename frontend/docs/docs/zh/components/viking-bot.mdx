# VikingBot 對話

可選 `locale: 'zh-CN' | 'en-US'` 覆蓋最近的模組或 Provider；均未配置時預設 `en-US`。已有 `labels` 可逐項覆蓋。業務內容仍由宿主提供。

對話檢視：訊息列表、輸入區與待確認互動區。開源版與火山版的宿主協議不同，元件只接收已歸一化的訊息模型，並把兩版渲染方式不同的區域交給宿主替換。

歡迎空態與輸入區沿用火山版佈局，訊息列表與輸入區複用 Ark Design。元件通過 props 接收資料，通過回撥上報操作，宿主負責實際會話、流式請求與上傳。歡迎文案可通過 `labels.welcomeTitle` 和 `labels.welcomeDescription` 替換，`emptyState` 可替換整個歡迎區。

回覆展示以火山版 `release/openviking/2026-11-12` 為基準：普通回覆直接使用 `MDRenderer`，正文為 13px / 22px、段間距 8px，長回覆不折疊。每輪最後一條回覆顯示懸停時間；Markdown 正文、行內程式碼及文本程式碼塊中的資源 URI 通過 `onOpenUri` 開啟。執行過程使用 `ActivityTimeline` 自帶的狀態、耗時和完成摺疊，工具詳情按輸入、輸出展示。`locale` 控制時間格式。

`tool` 或 `tool_result` 片段可傳入 `results: readonly VikingBotToolResultLink[]`，每項包含 `uri`、可選的 `label` 和 `score`，展示檔名、資源 URI 與相似度卡片。宿主負責適配檢索響應，元件不識別工具名稱或介面協議；卡片通過 `onOpenUri` 開啟，未提供回撥時不可點選。省略或傳空陣列時展示原始輸出。

## 兩版宿主怎麼接

| 差異           | 處理方式                                                             |
| -------------- | -------------------------------------------------------------------- |
| 訊息形態       | 統一為 `parts[]`，`role` 覆蓋 user、assistant、system、tool          |
| 執行時間線摺疊 | 片段用 `groupId` 歸組，`startedAt`、`durationMs` 參與展示            |
| 文本格式       | `text.format` 區分 `plain` 與 `markdown`                             |
| 工具呼叫       | `server`、`endpoint`、`durationMs` 覆蓋 MCP 語義                     |
| 訊息級動作     | `message.action` 宣告動作，`onMessageAction` 上報                    |
| 流式           | `{ parts, insertIndex, iteration }`；末尾追加時傳訊息數量            |
| 人工確認       | `components/viking-bot/interaction` 子路徑，四種內建表單加自定義渲染 |
| 渲染底座       | `messageList`、`composer`、`interaction`、`children` 四層替換        |

協議適配留在各宿主倉庫，元件不引入任何後端事件型別。

## 會話與輸入擴充套件

`sessions` 提供會話列表、當前 ID、載入/錯誤狀態和新建、選擇、分頁回撥；日期使用宿主提供的 ISO 時間。`headerActions` 承載可選的“更多”入口。元件不載入或持久化會話。`VikingBotSessionActions` 可單獨用於宿主的共享頂欄。

`quickInputs` 由宿主提供 `{ id, label, prompt, icon? }`，不內建業務指令。空態時顯示在歡迎區底部，有訊息時顯示在 Sender 上方；點選填入並聚焦，不自動傳送。選擇另一快捷項會替換此前插入的文案，保留其前後的自定義內容，包括手動輸入的相同文字。修改已插入文案的內部內容後，該段視為自定義文本，下一快捷項會追加；宿主替換草稿而無法明確對映編輯位置時，也會放棄該段的替換權。`onQuickInputSelect` 可接管這一行為。

`references` 包含 FileTree 的可見 `rows`、受控 `selected`、`onChange`，以及可選的 `onQueryChange`、`onExpand`、`isLoading` 和 `error`。按鈕 `@` 與輸入 `@` 共用選擇器，按 URI 去重，傳送時通過 `VikingBotDraft.references` 單獨上報；不把引用混成普通文本。未配置時隱藏入口。查詢、展開和許可權過濾由宿主完成；更新帳號或會話時，宿主同時更新選中引用和附件。`onFilesAdded` 啟用 `+`，僅上報檔案，由宿主上傳。

這些能力也可直接傳給獨立 `VikingBotComposer`。標題、說明、會話、引用、載入及移除按鈕的文案均通過 `labels` 定製。

互動不是後端暫停狀態：宿主從自己的流裡算出問題，答案發回後清除。元件內建 `choice`、`text`、`schedule`、`repair` 四種表單；需要樹選擇器、上傳器等宿主能力時，用 `custom` 自行渲染。

## 開發入口

獨立樣式入口為 `@openviking/react/components/viking-bot/style.css`，已包含主題基線，可獨立消費。

互動區的 `labels.answer` 設定文本答案的無障礙名稱，`labels.other` 設定預設自定義輸入提示；請求自帶的 `allowCustomInput.placeholder` 優先。內嵌互動區繼承 VikingBot 的 `locale`，也可通過 `interaction.locale` 區域性覆蓋。
