# VikingBot 對話

展示宿主提供的會話訊息，並提供輸入區和待確認互動區：傳送、停止、開啟資源等操作通過回撥交給宿主，元件不發起請求。

## 何時使用

- 需要在自己的頁面裡展示 AI 會話，包括回覆、推理與工具呼叫過程、輸入區和歷史會話入口時。
- 需要自己決定會話服務、流式請求和檔案上傳的接入方式時：元件只負責展示，不需要 `OpenVikingProvider`。
- 使用 [Console](../modules/console) 時，對話檢視已經內建，不需要單獨接入。

## 引入

```tsx
import { VikingBot } from '@openviking/react/components/viking-bot';
import '@openviking/react/components/viking-bot/style.css';
```

樣式入口已包含主題基線和檢視用到的 `@ark-design/ui` 樣式，可以單獨引入。

訊息列表、輸入區和待確認互動區由 `@ark-design/ui` 渲染。它是可選 peer 依賴，不會隨 `@openviking/react` 自動安裝，使用前需要安裝不低於 `0.0.0-beta.7` 的版本：

```bash
npm install @ark-design/ui@0.0.0-beta.7
```

只需要待確認互動區時，可以從 `interaction` 子路徑匯入 `VikingBotInteraction`，樣式入口相同：

```tsx
import { VikingBotInteraction } from '@openviking/react/components/viking-bot/interaction';
import '@openviking/react/components/viking-bot/style.css';
```

## 注意

- 元件不發起請求：會話的載入與儲存、流式連線、判斷一輪迴復何時結束和檔案上傳都由宿主處理。宿主需要把自己的訊息和流式事件轉換成 `VikingBotMessage` 和 `VikingBotStreamingState`。
- 根元素高度為父元素的 100%，訊息區在內部滾動，需要給父元素設定高度。
- 助手回覆按 Markdown 渲染，`format` 為 `'plain'` 的文本逐字顯示。正文、行內程式碼和 `bash`、`shell`、`sh`、`text`、`txt` 程式碼塊裡的 `viking://` 地址會變成連結，點選後傳給 `onOpenUri`。
- 助手回覆裡的 Markdown 連結只保留 `http`、`https`、`mailto`、`tel` 協議，其他協議的連結顯示為純文本；`http` 和 `https` 連結在新標籤頁開啟。
- 使用者訊息同樣按 Markdown 渲染，但其中的 `viking://` 地址不會變成連結。
- 相鄰且 `groupId` 相同的推理和工具呼叫片段合併為一個執行塊：標題欄顯示狀態和耗時，預設展開，可點選摺疊；每個工具呼叫可以展開檢視輸入和輸出。沒有 `groupId` 的片段各自成塊。
- 快捷輸入在草稿為空時直接填入，否則換行後追加；再選擇另一項會替換上一次填入的文案，保留前後使用者自己輸入的內容。
- 使用者修改了已填入的文案，或宿主整體替換草稿而無法確定修改位置時，這段文案視為使用者自己的內容，下一個快捷輸入改為追加。
- 在輸入框裡輸入 `@` 與點選 `@` 按鈕使用同一個選擇器，選中後引用加入 `references.selected`，輸入框裡的 `@` 查詢文字被刪除。引用按 URI 去重。
- 引用標籤顯示圖示和完整 URI，空間不足時省略並在標題中保留完整路徑；只顯示前 5 個，其餘收進 `+N`，懸停、聚焦或點選 `+N` 展開。
- 引用只出現在 `VikingBotDraft.references`，不會寫進草稿文本。切換帳號或會話時，宿主需要同時重置 `references.selected` 和 `attachments`。
- 待確認互動是宿主狀態，不是後端暫停：宿主根據自己的流生成問題，答案發回後清除 `interaction`。元件只渲染表單，並通過 `onSubmit` 上報答案。
- 訊息列表、輸入區和待確認互動區在首次渲染時才載入 `@ark-design/ui`，載入期間先顯示空容器。匯入 VikingBot 本身不會載入它，因此模組在沒有 `window` 的環境中也能匯入。
- `VikingBotComposer`、`VikingBotMessageList` 和 `VikingBotSessionActions` 可以單獨使用，例如把 `VikingBotSessionActions` 放進自己的頂欄。
- `groupMessages`、`groupByActivity` 和 `messageText` 與內建訊息列表使用同一套規則，自定義 `messageList` 時可以直接使用。
- `DEFAULT_LABELS` 和 `DEFAULT_INTERACTION_LABELS` 是內建的英文文案，列出了各自 `labels` 的全部鍵。
- 型別從 `@openviking/react/components/viking-bot` 匯出，包根入口只匯出 `VikingBot` 和 `VikingBotProps`。`VikingBotInputFeatures` 是 `VikingBot` 與 `VikingBotComposer` 共有的 `quickInputs`、`onQuickInputSelect` 和 `references`。

## 請求與會話

使用 [VikingBot 無頭模組](../modules/viking-bot) 獲取請求、會話和狀態管理；元件本身只接收資料與回撥。[Console](../modules/console) 已內建接入該模組。
