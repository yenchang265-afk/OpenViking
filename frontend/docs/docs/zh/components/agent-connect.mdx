# AgentConnect Agent 接入

Agent 接入面板，列出主流 Agent 和 MCP、CLI、API、SDK 四種開發方式，展示接入說明和可複製的程式碼塊，其中的 API Key 預設脫敏。

## 何時使用

- 需要引導使用者把 OpenViking 接入 Codex、Claude Code、Cursor 等 Agent，或通過 MCP、CLI、API、SDK 自行開發時。
- 需要自己決定 API Key 和服務地址的來源時：元件只負責展示和複製，不發起請求，也不需要 `OpenVikingProvider`。
- 需要放在檔案瀏覽區頂部時，使用 [FileBrowserActionBar](./file-browser-action-bar)，它通過 `agentConnect` 在右側抽屜中展示本元件。

## 引入

```tsx
import { AgentConnect } from '@openviking/react/components/agent-connect';
import '@openviking/react/components/agent-connect/style.css';
```

## 程式碼演示

### 基礎用法

切換「接入主流 Agent」「開發自己的 Agent」兩個頁籤，選擇左側條目檢視接入說明。點選程式碼塊上的按鈕可以複製，也可以顯示或隱藏其中的 API Key。

示例中的 `apiKey` 僅用於演示，請換成宿主自己的金鑰。

## API

### AgentConnect

| 引數             | 說明                                                                                               | 型別                                        | 預設值                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------- |
| apiKey           | 寫入接入說明的 API Key，介面脫敏顯示，複製時使用原值                                               | `string`                                    | 必填                                                    |
| baseUrl          | OpenViking 服務地址，替換接入說明裡的預設地址                                                      | `string`                                    | `https://api.vikingdb.cn-beijing.volces.com/openviking` |
| agreementUrl     | 使用者協議連結，提供後頁尾顯示協議連結，省略時只顯示資料訪問提示                                     | `string`                                    | -                                                       |
| showOverseasTag  | 「境外」標籤的範圍：省略時標記 Codex 和 Claude Code，`true` 標記全部適用的 Agent，`false` 隱藏標籤 | `boolean`                                   | -                                                       |
| activeTabId      | 受控的當前頁籤，省略時由元件維護                                                                   | `'mainstream' \| 'custom'`                  | `'mainstream'`                                          |
| selectedId       | 受控的選中條目，取值為 `AgentConnectItem` 的 `id`，當前頁籤不含該條目時顯示第一項                  | `string`                                    | 當前頁籤的第一項                                        |
| onTabChange      | 選擇頁籤時觸發，點選、方向鍵、Home、End 都會觸發                                                   | `(tabId: 'mainstream' \| 'custom') => void` | -                                                       |
| onSelect         | 選擇條目時觸發                                                                                     | `(item: AgentConnectItem) => void`          | -                                                       |
| onCopy           | 複製成功後觸發，引數是實際複製的程式碼塊或整段說明，包含原始 API Key                                 | `(text: string) => void`                    | -                                                       |
| locale           | 介面語言，規則見[國際化](../guide/i18n)                                                            | `'zh-CN' \| 'en-US'`                        | 繼承上級，預設 `'en-US'`                                |
| className、style | 外觀與佈局，其餘 HTML 屬性透傳到根元素                                                             | HTML 屬性                                   | -                                                       |

### AgentConnectItem

| 引數 | 說明                     | 型別     | 預設值 |
| ---- | ------------------------ | -------- | ------ |
| id   | 內建條目的標識，取值見下 | `string` | 必填   |
| name | 條目在當前語言下的名稱   | `string` | 必填   |

內建條目的 `id`：

- `mainstream` 頁籤（接入主流 Agent）：`codex`、`claude-code`、`doubao`、`workbuddy`、`trae`、`cursor`、`openclaw`、`hermes`、`opencode`、`deepseek-harness`、`deerflow`、`pi`、`zcode`、`kimi-code`。
- `custom` 頁籤（開發自己的 Agent）：`mcp`、`cli`、`api`、`sdk`。

## 注意

- Agent 目錄、接入說明和圖示內建，不提供增刪或替換的 prop。語言只能通過 `locale` 切換，元件沒有語言選擇介面。
- 接入內容和圖示隨元件打包，不需要配置資源地址，執行時不請求遠端文件。元件不執行說明裡的命令，只負責展示和複製。
- 預設寬 1000px、最小高度 949px，容器更窄時橫向滾動。
- 程式碼塊裡的 API Key 預設顯示為 `••••••••`，點選程式碼塊上的「顯示 API Key」檢視原值，同一份說明裡一次只顯示一個程式碼塊的金鑰。複製始終使用原始金鑰，與顯示狀態無關。
- 元件不持久化 `apiKey`，也不把它寫進 DOM 屬性。`onCopy` 收到的文本包含原始 API Key，宿主按憑據處理，不要寫入日誌。
- 複製使用 Clipboard API，需要安全上下文（如 HTTPS）和剪貼簿許可權。失敗時顯示「複製失敗，請重試」，不會呼叫 `onCopy`。
- DeerFlow 和 CLI 的詳情帶有說明頁籤：DeerFlow 為 MemoryManager 與 MCP，CLI 為「手動終端安裝」與「通過 AI Agent 安裝」。預設選中第一個，複製的是當前選中的說明。
- 切換條目、說明頁籤、語言、`apiKey` 或 `baseUrl` 後，金鑰顯示和複製反饋恢復初始狀態。此前發起的複製完成後不再更新介面，也不呼叫 `onCopy`。
- TRAE 的安裝命令面向國際版。
- Hermes 使用自定義 `baseUrl`（不同於預設地址）時，說明改用 Custom 連線步驟。
- 「境外」標籤顯示在詳情標籤行的末尾，按 Agent 產品的歸屬標記，不根據它使用的模型推斷部署地區。`showOverseasTag` 為 `true` 時，除 Codex 和 Claude Code 外，還標記 Cursor、OpenClaw、Hermes Agent、OpenCode 和 pi。
- 型別從 `@openviking/react/components/agent-connect` 匯出，包根入口只匯出元件和 `AgentConnectProps`。
