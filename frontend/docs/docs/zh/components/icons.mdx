# Icons 圖示

元件庫內建的圖示：箭頭、檔案型別、作用域層級和看板圖示以 React 元件提供，渲染為內聯 SVG；另有按檔名選擇檔案型別圖示的函式。

## 何時使用

- 需要與元件庫介面一致的圖示時，例如為 [ScopeSwitcher](./scope-switcher) 的選項或 [FileTree](./file-tree) 的行提供圖示。
- 需要按檔名顯示對應型別的圖示時，使用 `getFileTypeIcon`。

## 引入

```tsx
import { PdfIcon, getFileTypeIcon } from '@openviking/react/icons';
```

圖示以內聯 SVG 打包進 JavaScript，沒有單獨的資源請求，不需要匯入樣式表。

## API

### 圖示元件通用屬性

清單中的圖示元件（`LibraryIcon` 除外）渲染為內聯 `svg`，接收 `IconProps`。

| 引數             | 說明                                                                                             | 型別                      | 預設值                     |
| ---------------- | ------------------------------------------------------------------------------------------------ | ------------------------- | -------------------------- |
| width            | 圖示寬度                                                                                         | `number \| string`        | 圖示自帶的尺寸，見圖示清單 |
| height           | 圖示高度                                                                                         | `number \| string`        | 圖示自帶的尺寸，見圖示清單 |
| aria-label       | 無障礙名稱；省略時 SVG 帶 `aria-hidden`，作為裝飾；傳入後圖標保留在無障礙樹中                    | `string`                  | -                          |
| className、style | 為 SVG 元素設定類名和內聯樣式；跟隨文字顏色的圖示用 `color` 改色                                 | `string`、`CSSProperties` | -                          |
| 其他屬性         | 標準 SVG 屬性，包括 `aria-*` 和 `role`，不接收 `children`；顯式傳入的 `aria-hidden` 優先於預設值 | SVG 屬性                  | -                          |

### LibraryIcon

固定為 14 × 14 的圓形漸變色塊，渲染為 `span`，不接收 SVG 屬性，也不進入無障礙樹。

| 引數 | 說明                                                                   | 型別     | 預設值 |
| ---- | ---------------------------------------------------------------------- | -------- | ------ |
| name | 決定使用五組漸變中的哪一組，同一個名稱始終得到同一組；省略時使用第一組 | `string` | `''`   |

### VikingBotIcon

對話相關的圖示，用 `name` 選擇，其餘屬性同圖示元件通用屬性。

| 引數          | 說明                                                                                         | 型別                                                                                                                              | 預設值 |
| ------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------ |
| name          | 圖示名稱，依次為燈泡、書本、影片、報告、歷史、新建會話、移除、工具、上下文資料夾、關閉上下文 | `'bulb' \| 'book' \| 'video' \| 'report' \| 'history' \| 'newSession' \| 'remove' \| 'tool' \| 'contextFolder' \| 'contextClose'` | 必填   |
| width、height | 圖示尺寸                                                                                     | `number \| string`                                                                                                                | `16`   |

### 檔案型別圖示函式

| 函式                     | 說明                                                                           | 型別                                                  |
| ------------------------ | ------------------------------------------------------------------------------ | ----------------------------------------------------- |
| `getFileTypeIcon`        | 取得檔名對應的圖示元件，沒有匹配時返回通用檔案圖示                             | `(name: string) => FileTypeIconComponent`             |
| `resolveFileTypeIconKey` | 取得檔名對應的圖示鍵，沒有匹配時返回 `'default'`                               | `(name: string) => string`                            |
| `getFileTypeColor`       | 取得圖示鍵的品牌色，`scheme` 預設為 `'light'`，未登記的鍵返回 `'currentColor'` | `(key: string, scheme?: 'light' \| 'dark') => string` |

`name` 可以是檔名或路徑，只取最後一段並忽略大小寫：先匹配完整檔名，再按副檔名從長到短匹配（`tar.gz` 先於 `gz`），都沒有命中時使用通用檔案圖示。

返回的檔案型別圖示使用 `currentColor`，PDF、PPT、Word、音訊和影片圖示除外，它們自帶固定配色。用 `getFileTypeColor` 取得品牌色後設置 `color`：

```tsx
import {
  getFileTypeColor,
  getFileTypeIcon,
  resolveFileTypeIconKey,
} from '@openviking/react/icons';

function FileTypeIcon({ name }: { name: string }) {
  const Icon = getFileTypeIcon(name);
  return (
    <Icon
      aria-hidden="true"
      width={16}
      height={16}
      style={{ color: getFileTypeColor(resolveFileTypeIconKey(name)) }}
    />
  );
}
```

## 主題變數

`LibraryIcon` 有五組漸變，亮色和暗色主題使用同一組。用 `--ov-ui-color-library-swatch-1` 到 `--ov-ui-color-library-swatch-5` 逐組覆蓋；沒有載入庫樣式表時，元件使用內建的同一組漸變。

```css
:root {
  --ov-ui-color-library-swatch-1: linear-gradient(145deg, #e0f7fa, #80deea);
}
```

## 注意

- 清單中的圖示預設帶 `aria-hidden`，作為裝飾。圖示單獨傳達資訊時，傳入應用語言的 `aria-label`；旁邊的文字已經說明含義時省略，避免重複播報。
- `getFileTypeIcon` 返回的元件用於裝飾時，請顯式傳入 `aria-hidden`。
- 圖示沒有互動行為：放進按鈕時，按鈕語義、鍵盤互動和焦點樣式由宿主提供。
- 型別 `IconProps`、`IconComponent`、`FileTypeIconComponent` 和 `VikingBotIconName` 同樣從 `@openviking/react/icons` 匯出；包根入口不匯出圖示。
