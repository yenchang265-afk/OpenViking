# ExperienceDashboard 經驗看板

展示 Agent 經驗的使用情況：目錄檢視列出經驗檔案，檔案檢視展示單個經驗的應用效果、來源軌跡和測試材料。

## 何時使用

- 需要在檔案瀏覽中檢視經驗的使用效果，並跳轉到具體的經驗或軌跡時。
- 需要自己決定資料來源、分頁和頁面佈局時：元件只負責展示，不發起請求，也不需要 `OpenVikingProvider`。
- 使用 [FileBrowser](../modules/file-browser) 時，看板已經內建，不需要單獨接入。

## 引入

```tsx
import { ExperienceDashboard } from '@openviking/react/components/experience-dashboard';
import '@openviking/react/components/experience-dashboard/style.css';
```

## 程式碼演示

### 基礎用法

切換「經驗目錄」「經驗檔案」「宿主資料」「失敗狀態」檢視四種狀態，頁籤支援方向鍵和 Home/End。「宿主資料」補充了應用效果指標和測試材料：未提供 `effect` 時指標顯示「—」，提供 `testMaterials` 後才出現「測試」頁籤。

### ExperienceDashboard

| ---------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| uri              | 當前資源的 URI，變化時重置頁籤、時間範圍等內部狀態                                                                    | `string`                                                                                                                | 必填                     |
| kind             | 展示模式，不根據 `uri` 推斷：`directory` 列出經驗檔案，`file` 展示單個經驗的看板                                      | `'directory' \| 'file'`                                                                                                 | 必填                     |
| data             | 展示資料，沒有資料的區域顯示 `states` 對應的狀態                                                                      | `ExperienceDashboardData`                                                                                               | `{}`                     |
| tab              | 檔案檢視的當前頁籤：`impact` 應用效果、`source` 來源追溯、`test` 測試。傳入後受控，需要在 `onTabChange` 裡更新        | `'impact' \| 'source' \| 'test'`                                                                                        | `'impact'`               |
| days             | 「應用效果」的統計時間範圍，單位為天，可選 `3`、`7`、`30`，`0` 表示全部時間。傳入後受控，需要在 `onDaysChange` 裡更新 | `number`                                                                                                                | `7`                      |

| onLoadMore       | 點選「載入更多」時觸發，由宿主追加下一頁；優先於 `onPageChange`，省略時回退到 `onPageChange(page + 1)`                | `() => void`                                                                                                            | -                        |
| onOpenUri        | 點選經驗名稱或軌跡的開啟按鈕時觸發，引數為對應的 URI；省略時這些按鈕停用                                              | `(uri: string) => void`                                                                                                 | -                        |
| labels           | 覆蓋介面文案                                                                                                          | `Partial<ExperienceDashboardLabels>`                                                                                    | -                        |
| slots            | 替換渲染異常的展示內容，見[錯誤展示插槽](../guide/getting-started#自定義錯誤展示)                                     | `{ errorFallback?: ReactNode \| ((reset: () => void) => ReactNode) }`                                                   | -                        |

| ------- | ------------------------------------------------------------------------------ | --------------- | ------ |

## 注意

- `states` 的鍵與區域對應，通常只在對應區域沒有資料時顯示：`list` 目錄檢視的列表，`effect` 應用效果的三個指標，`outcomes` 任務結果分佈，`trajectories` 注入軌跡，`sources` 來源追溯，`tests` 測試材料。有兩處例外：追加軌跡頁失敗時，已載入的記錄保留，錯誤與重試顯示在列表下方；`effect` 的 `loading` 或 `error` 一旦給出，即使 `data.effect` 仍有值也整塊替換為骨架或錯誤，因為指標是獨立取數的，舊值不能與重新整理失敗同時顯示。
- 分頁在超過一頁時出現：`data.total` 與 `pageSize` 決定頁數，沒有 `data.total` 時由 `hasMore` 界定。對應區域的 `loading` 為 `true` 時翻頁按鈕停用。
- 「應用效果」頁簽在 `hasMore` 為 `true` 時提供「向下滾動載入更多」：滾到距底部 240px 內自動追加，也可點選按鈕；優先呼叫 `onLoadMore`，只提供 `onPageChange` 時以 `page + 1` 呼叫它。停在同一位置不會連續請求，往回滾或離開觸發區後再次回到末尾才會再請求一次——請求失敗時內容不會變高，重試同一頁靠的就是這條；`loadingMore` 為 `true` 期間顯示載入中。
- 更新測試材料會保留已選頁籤與時間範圍；`testMaterials` 變回 `undefined` 時，已選中的「測試」頁籤回到「應用效果」。
- 複製使用 `navigator.clipboard.writeText`，只在 HTTPS 或 localhost 下可用；不可用或瀏覽器拒絕時按鈕顯示「複製失敗」。
- 元件高度為 `100%` 且內容區自己滾動，父元素需要給出高度。
- 型別從 `@openviking/react/components/experience-dashboard` 匯出，包括 `ExperienceDashboardTab` 和 `ExperienceOutcome`；包根入口只匯出元件和 `ExperienceDashboardProps`。
