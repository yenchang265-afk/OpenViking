# ScopeCascade 級聯選擇

可選 `locale: 'zh-CN' | 'en-US'` 覆蓋最近的模組或 Provider；均未配置時預設 `en-US`。已有 `labels` 可逐項覆蓋。業務內容仍由宿主提供。

直接向 `ScopeCascade` 傳入三個 API 適配函式。請求、級聯、取消、重試和各級訂閱均內建，不需要建立控制器或呼叫 Hook。


三個介面返回 `Promise<readonly ScopeSwitcherOption[]>`，選項為 `{ id, label, icon?, description?, disabled? }`。鑑權、介面地址和響應對映由適配函式負責。保持函式引用穩定；適配函式變化會取消舊請求並重置全部選擇。帳號切換可用元件 `key` 隔離。

預設檢視內建三個層級圖示：庫用 `LibraryIcon`（按 id 取色的圓形漸變塊），空間與使用者用 `SpaceIcon`、`UserIcon`。適配函式返回的選項沒有 `icon` 時自動補上本級預設圖示，返回了 `icon` 就照用宿主的。

| 介面            | 引數                                                      |
| --------------- | --------------------------------------------------------- |
| `loadLibraries` | `signal: AbortSignal`                                     |
| `loadSpaces`    | `libraryId: string, signal: AbortSignal`                  |
| `loadUsers`     | `libraryId: string, spaceId: string, signal: AbortSignal` |

掛載後加載庫列表，每級預設選擇第一個可用項並繼續載入下一級。切換上級時先清空下游，舊請求即使忽略 signal 也不能覆蓋新結果。各級內部獨立訂閱，錯誤隻影響本級；預設檢視封裝本地搜尋、載入、空態、錯誤與重試。當前載入完整列表，不提供服務端搜尋或分頁。

`onChange(selection)` 返回完整的 `{ libraryId, spaceId, userId }`。初始化、上級切換或介面重置導致身份不完整時返回 `null`；同一身份的重新整理不重複上報。宿主在非空時載入對應業務資料，不需要訂閱內部狀態。

## 屬性

三個 `load*` 介面必填。`onChange` 可選，`levelNames` 按庫、空間、使用者順序指定名稱；`labels` 設定載入、搜尋、空態和錯誤文案，`retryLabel` 設定重試按鈕文案。`className`、`style` 等 HTML 屬性透傳給佈局容器。引入 `@openviking/react/modules/scope-cascade/style.css` 使用預設樣式。
