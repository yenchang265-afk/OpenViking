# ScopeCascade 級聯選擇

依次選擇知識庫、資料空間和使用者的三級選擇器：上級變化時，下級清空並重新載入，三級都選中後通過 `onChange` 返回完整身份。

## 何時使用

- 需要依次選擇知識庫、資料空間和使用者，再按選中的身份載入業務資料時。
- 資料來自宿主自己的介面時：元件通過三個載入函式取數，請求、級聯、取消和重試都由元件管理。它不請求 OpenViking 原生 API，因此沒有 `requestOptions`，也不需要 `OpenVikingProvider`；其他區塊的請求配置見[區塊概覽](../modules/)。
- 需要自己管理各級資料、自定義面板或固定某一級時，改用 [ScopeSwitcher](../components/scope-switcher)。

## 引入

```tsx
import { ScopeCascade } from '@openviking/react/modules/scope-cascade';
import '@openviking/react/modules/scope-cascade/style.css';
```

## API

### ScopeCascade

| 引數             | 說明                                                                                                               | 型別                                                                                                   | 預設值                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| loadLibraries    | 載入知識庫列表，掛載時呼叫；`signal` 在請求過期時中止                                                              | `(signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>`                                     | 必填                                                                               |
| loadSpaces       | 載入知識庫下的資料空間，選中知識庫後呼叫                                                                           | `(libraryId: string, signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>`                  | 必填                                                                               |
| loadUsers        | 載入資料空間下的使用者，選中資料空間後呼叫                                                                           | `(libraryId: string, spaceId: string, signal: AbortSignal) => Promise<readonly ScopeSwitcherOption[]>` | 必填                                                                               |
| levelNames       | 三級的名稱，依次為知識庫、資料空間、使用者；未選中時顯示在觸發器上，同時是觸發器的無障礙名稱                         | `readonly [string, string, string]`                                                                    | `zh-CN`：`['知識庫', '資料空間', '使用者']`；`en-US`：`['Library', 'Space', 'User']` |
| onChange         | 選擇變化時觸發，三級都選中時引數為 `ScopeCascadeSelection`，身份不完整時為 `null`；同一身份不重複觸發              | `(selection: ScopeCascadeSelection \| null) => void`                                                   | -                                                                                  |
| retryLabel       | 載入失敗後重試按鈕的文案                                                                                           | `string`                                                                                               | `zh-CN`：`'重試'`；`en-US`：`'Retry'`                                              |
| labels           | 覆蓋介面文案：載入中 `loading`、搜尋框佔位 `searchPlaceholder`、無選項 `empty`、無匹配 `noMatch`、載入失敗 `error` | `ScopeSwitcherLabels`                                                                                  | -                                                                                  |
| locale           | 介面語言，規則見[國際化](../guide/i18n)                                                                            | `'zh-CN' \| 'en-US'`                                                                                   | 繼承上級，預設 `'en-US'`                                                           |
| className、style | 外觀與佈局，其餘 HTML 屬性透傳到根元素                                                                             | HTML 屬性                                                                                              | -                                                                                  |

### ScopeSwitcherOption

載入函式返回的選項。

| 引數        | 說明                                                                                       | 型別        | 預設值  |
| ----------- | ------------------------------------------------------------------------------------------ | ----------- | ------- |
| id          | 選項的唯一標識；上級的 `id` 會傳給下一級的載入函式，三級的 `id` 組成 `onChange` 返回的身份 | `string`    | 必填    |
| label       | 顯示文本，搜尋時按它過濾並高亮匹配的片段                                                   | `string`    | 必填    |
| icon        | 選項行首的圖示，省略時使用本級預設圖示                                                     | `ReactNode` | -       |
| description | 顯示在標籤下方的次要說明                                                                   | `string`    | -       |
| disabled    | 停用該選項：置灰、不可點選，也不會被自動選中                                               | `boolean`   | `false` |

### ScopeCascadeSelection

| 引數      | 說明              | 型別     | 預設值 |
| --------- | ----------------- | -------- | ------ |
| libraryId | 選中的知識庫 id   | `string` | 必填   |
| spaceId   | 選中的資料空間 id | `string` | 必填   |
| userId    | 選中的使用者 id     | `string` | 必填   |

## 注意

- 載入函式需要保持引用穩定，例如定義在元件外，或用 `useCallback` 包裹。任一函式的引用變化，都會取消進行中的請求、清空全部選擇並從知識庫重新載入。
- 切換帳號時，給元件設定 `key={accountId}`，讓選擇狀態一起重置。
- 掛載後先載入知識庫，每一級自動選中第一個未停用的選項，再載入下一級。上級沒有選中項時，下級保持停用；某一級沒有可選項時，下級保持停用，`onChange` 返回 `null`。
- 上級變化時，下級先清空再重新載入。遲到的舊響應即使載入函式忽略了 `signal`，也會被丟棄。
- 某一級載入失敗時，只有該級顯示錯誤和重試按鈕，下級保持停用；點選重試只重新載入該級。
- 每一級一次返回完整列表，不支援服務端搜尋和分頁。超過 10 項時顯示搜尋框，在本地按選項文字過濾。
- 選項沒有 `icon` 時，知識庫顯示 [LibraryIcon](../components/icons)（按 `id` 取色的圓形漸變色塊），資料空間和使用者分別顯示 `SpaceIcon`、`UserIcon`；載入函式返回了 `icon` 就使用它。
- 型別從 `@openviking/react/modules/scope-cascade` 匯出：`ScopeCascadeProps`、`ScopeCascadeSelection`，以及三個載入函式合在一起的 `ScopeCascadeApi`；`ScopeSwitcherOption` 和 `ScopeSwitcherLabels` 從 `@openviking/react/components/scope-switcher` 匯出。包根入口只匯出元件和 `ScopeCascadeProps`。
