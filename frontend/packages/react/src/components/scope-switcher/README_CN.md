# ScopeSwitcher

[English](README.md) / 中文

由多級獨立選擇器組成的作用域麵包屑：`ScopeSwitcher` 負責排列，每一級（例如庫、資料空間、使用者）用一個 `ScopeSelector` 展示當前值並切換。

- 公開入口：`@openviking/react/components/scope-switcher`，樣式 `@openviking/react/components/scope-switcher/style.css`
- 文件：[元件文件](../../../../../docs/docs/zh/components/scope-switcher.mdx)
