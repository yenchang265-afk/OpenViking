# TUI

[English](README.md) / 中文

可選 `locale: 'zh-CN' | 'en-US'` 覆蓋最近的模組或 Provider；均未配置時預設 `en-US`。已有 `labels` 可逐項覆蓋。業務內容仍由宿主提供。

當前命令記錄、結果與輸入區的檢視和互動。記錄區、空態、輸入、命令建議與引數幫助組成 TUI 主體。命令描述和執行記錄由宿主傳入；元件通過 `onSubmit` 上報提交意圖，通過 `onCopy` 通知複製完成。

`tui.tsx` 對應 `@openviking/react/components/tui`。檢視已按本文契約實現：渲染命令記錄與結果、空態，以及帶補全和引數提示的受控輸入。欄位清單以型別宣告為準，本文不重複列舉。

## 職責邊界

- TUI 只包含命令記錄與結果區、輸入區及其建議和幫助。新建會話、歷史記錄面板、檢視與使用者切換、外層工具欄由宿主通過獨立元件組合，不放進 TUI，也不提供對應插槽。
- 宿主處理新建會話、歷史選擇與清空，再更新 `records` 和 `value`；TUI 僅渲染當前傳入的記錄，不維護歷史列表或專門的歷史預覽狀態。
- 命令執行完全在宿主。元件使用宿主命令描述提供輸入互動，執行結果按宿主給出的內容變體渲染。
- 結果內容用聯合型別表達，包含通用文本與六種結構化結果；未歸類結果通過通用文本展示。
- 輸入是受控的。元件內部接受命令或示例後，通過 `onValueChange` 更新輸入，不提交命令。
- 輸入區是整寬的無邊框編輯區域，帶頂部分隔線，編輯區域最小高度 80px，底部快捷鍵引導高 40px。聚焦時分隔線保持原色。內容最多自適應增高至三行，超出後滾動；底部依次顯示 `/ 全部指令`、`↑ 歷史指令`、`↵ 傳送`。↑/↓ 可回填當前記錄中的命令，Enter 提交，Shift+Enter 換行，不單獨渲染髮送按鈕。
- 輸入 `o` 時會以灰字提示 `v`，按 Tab 接受字首；也可直接按空格補成 `ov `。在 `ov ` 後按 Tab 開啟全部命令，繼續輸入字母可篩選候選並預覽剩餘文字，再按 Tab 接受行內提示或已選中的命令。普通輸入只顯示行內提示，`/` 和顯式 Tab 才展開列表；補全根據宿主的 `inputText` 推導。普通 Tab 始終保留輸入區焦點：無補全、輸入引數或游標位於中間時保持原值和頁面位置；Shift+Tab 可移出輸入區。灰字不會進入提交值。
- 輸入 `/`，或在 `ov ` 後按 Tab，都會展開未選中任何命令的候選列表；篩選或重新開啟時也清除選中狀態。未選擇時，↓ 從第一項開始，↑ 從最後一項開始。懸停或使用方向鍵選擇後，側邊才顯示示例與參數列。沒有關鍵字也未選擇候選時，Tab 不填入命令。橫向空間不足時，詳情與列表上下排列。Esc 或點選區域外可關閉浮層；不支援原生 Popover 的瀏覽器回退為內聯面板。
- 輸入區與命令記錄統一使用灰色 CLI 字首、正文色加重的命令名、連結色資源 URI；連結僅在 hover 時顯示下劃線。命令記錄按同一份 `inputText` 顯示，引數原樣保留；時間單獨位於下一行並右對齊。複製和歷史回填使用相同字首，未匹配目錄的命令按原文顯示。
- 宿主可傳入 `createdAtMs`（Unix 毫秒）：元件顯示“剛剛”、1 小時內的整分鐘數、24 小時內的整小時數，之後顯示本地時區的 `YYYY-MM-DD HH:mm`。無有效時間戳時回退到可選的 `createdAt` 展示字串，不解析該字串。SSR/hydration 先使用兜底文案，客戶端接管後再格式化；時間隨渲染重新計算，不設定獨立定時重新整理。`labels.justNow`、`labels.formatMinutesAgo` 和 `labels.formatHoursAgo` 可覆蓋本地化時間文案。
- 接受命令後，輸入區使用宿主提供的 `inputText` 字首（預設 `name`）並按上述層級顯示，後面直接顯示位置引數提示；沒有位置引數時顯示必填選項。開始輸入引數後佔位收起，不寫入受控值。完整詳情僅在命令候選列表展開時展示。
- `locale` 選擇英文（`en-US`）或中文（`zh-CN`）介面文案，`labels` 可逐項覆蓋；命令和結果文案由宿主本地化。示例跟隨文件站語言。
- `onSubmit` 上報顯式提交意圖。宿主負責請求、許可權和執行，並通過 `records` 更新等待、成功或失敗的記錄；已有等待記錄不阻止後續提交。
- `onOpenUri` 在輸入區、命令氣泡或結果中的 URI 連結啟用時收到原始地址，由宿主負責開啟。未傳回調時，純文本連結使用原生 `href`。
- 複製由元件完成，成功後通過 `onCopy` 通知宿主，引數為已複製的文本；失敗時不觸發該回調。省略回撥不影響複製。
- 命令篩選、高亮、鍵盤選擇、填入和引數幫助由元件處理。宿主提供 `commands` 和可選 `commandGroups`，包含本地化的說明、引數、選項及示例。元件不取數，不讀寫本地儲存。
- `quickCommands` 列出內建空態展示的命令名稱，按陣列順序從 `commands` 解析，未命中的名稱跳過，重複名稱只保留首次出現。標題、說明與列表由元件渲染，點選後填入並聚焦輸入框，不提交命令。`emptyState` 會完全替換內建空態；傳 `null` 不顯示，兩者都不傳也不顯示。
- 元件介面文案與引導提示統一通過 `labels` 配置。`disabled` 獨立控制命令輸入與提交的可用性，`labels.unavailableMessage` 提供停用時的提示；僅設定文案不會停用元件。

命令描述和分組由宿主提供，沿用現有描述和結果型別的新增命令無需釋出元件。示例目錄位於 `docs/docs/_demos/tui-commands/`，元件不再內建業務目錄。省略 `commands` 時仍可輸入和提交文本，但不展示候選或引數幫助。

結果卡片共用命令標題與帶無障礙名稱的狀態圖示。匹配到宿主命令時，標題使用其 `inputText`，不帶引數，正文中的同名命令標題不重複顯示。寫入結果逐行使用獨立底色，狀態結果使用帶底色的鍵值行；資源預覽保留獨立的正文佈局，JSON 與 Markdown 程式碼塊共用可複製的程式碼檢視。命令成功不代表返回任務已經結束。空結果與幫助文案由 `labels.noResult`、`labels.availableCommands`、`labels.helpHint` 配置。

結果按七種 `TuiRecordContent` 變體分別渲染：`text`（純文本或 Markdown，JSON 自動縮排）、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 與 `command-help`。輸入區、命令氣泡、Markdown 和結構化結果字串中的資源 URI 連結共用 `onOpenUri`。自定義 ReactNode 內部的連結由宿主處理。點選輸入區連結不會改變或提交命令；Shift+Tab 可聚焦連結，再按 Enter 啟用。`resource-tree` 在有 `detailRows` 時按列對齊成表格，否則逐行展示並每 20 條分頁。

## 結果內容

`TuiRecordContent` 包含 `text`、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 和 `command-help` 七種變體。

- `text` 通過 `format` 區分 `plain` 與 `markdown`，預設為 `plain`。JSON 格式化後作為文本展示。
- 失敗通過 `TuiRecord.status: 'error'` 表達，錯誤正文使用通用文本，不單獨定義錯誤內容變體。
- 命令幫助內容與其他執行結果均由宿主使用現有結果型別提供。

從 CLI 輸出到這些變體的轉換仍由宿主負責，元件不解析命令輸出。

## 可選能力

部分欄位表達的是宿主能力，不傳即降級為對應表現：

| 欄位           | 不傳時         | 傳值時的表現                                                     |
| -------------- | -------------- | ---------------------------------------------------------------- |
| 空態           | 不顯示         | `quickCommands` 渲染內建空態；`emptyState` 替換它，`null` 不顯示 |
| 檢索層級與型別 | 不顯示對應標籤 | 分別在標題旁和分數旁展示標籤                                     |
| 分數詳情       | 分數僅顯示文本 | 提供分數文案時，懸停或聚焦顯示宿主詳情內容                       |

記錄為 `pending` 時，元件按命令名或別名匹配宿主目錄，使用描述的可選 `skeleton`；未提供或未識別時使用通用骨架。等待時可省略 `content`。

`disabled` 預設為 `false`。設為 `true` 時停用命令輸入與提交，並展示 `labels.unavailableMessage`；未覆蓋該文案時使用當前 `locale` 的預設提示。

## 開發入口

開發與構建入口見 [前端工作區 README](../../../../../README.md)，模組約定見[包說明](../../../README.md)。

獨立樣式入口為 `@openviking/react/components/tui/style.css`。類名使用 `ov-tui__<元素>`，顏色取自 `--ov-ui-*` 主題變數並帶主題中性的回退值，淺色與暗色宿主下都可直接使用。
