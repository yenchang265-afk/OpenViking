# TUI

[English](README.md) / 中文

當前命令記錄、結果與輸入區的檢視和互動。記錄區、空態、輸入、命令建議與引數幫助組成 TUI 主體。執行結果由上層傳入；命令傳送、資源開啟和複製成功後通過回撥通知宿主，失敗時不觸發對應回撥。

`tui.tsx` 對應 `@openviking/react/components/tui`。當前是佔位元件：只渲染固定尺寸的空殼，不消費 props，用於先行釋出包供宿主對照 API。真實實現按本文與型別宣告重寫，介面以原始碼為準，本文不重複列舉。

## 職責邊界

- TUI 只包含命令記錄與結果區、輸入區及其建議和幫助。新建會話、歷史記錄面板、檢視與使用者切換、外層工具欄和底部快捷鍵說明由宿主通過獨立元件組合，不放進 TUI，也不提供對應插槽。
- 宿主處理新建會話、歷史選擇與清空，再更新 `records` 和 `value`；TUI 僅渲染當前傳入的記錄，不維護歷史列表或專門的歷史預覽狀態。
- 命令執行完全在宿主。元件複用共享命令後設資料提供輸入互動，執行結果按宿主給出的內容變體渲染。
- 結果內容用聯合型別表達，包含通用文本與六種結構化結果；未歸類結果通過通用文本展示。
- 輸入是受控的。元件內部接受補全或引數提示後，通過 `onValueChange` 更新輸入，不提交命令。
- `onSubmit` 僅在命令成功傳送後通知命令文本，傳送失敗時不觸發。該通知不承擔傳送，也不表示後臺命令已執行完成；傳送過程不依賴通知的返回值。宿主通過 `records` 更新後續結果與錯誤；後臺任務記錄仍為 `pending` 時，不阻止後續提交。
- `onOpenUri` 在資源成功開啟後通知已開啟的 URI，失敗時不觸發；導航執行能力由接入層負責。
- 複製由元件完成，成功後通過 `onCopy` 通知宿主，引數為已複製的文本；失敗時不觸發該回調。省略回撥不影響複製。
- 命令匹配、候選列表、高亮與鍵盤選擇、引數提示及幫助面板由元件內部統一處理。命令名稱、引數、說明和示例必須複用 CLI 的同一份命令後設資料，宿主不逐條維護或渲染命令幫助；元件不自行取數或讀寫本地儲存。
- `emptyState` 是完整空態的唯一配置入口，可組合標題、說明和快捷入口，相關互動由宿主在節點內處理。無記錄時展示該節點；省略時使用 `labels.empty`，傳 `null` 時隱藏空態內容。
- 元件介面文案與引導提示統一通過 `labels` 配置。`disabled` 獨立控制命令輸入與提交的可用性，`labels.unavailableMessage` 提供停用時的提示；僅設定文案不會停用元件。

當前僅定義介面邊界，尚未實現補全、幫助面板或接入 CLI 共享命令後設資料；新增 CLI 命令的自動同步需在真實實現中打通該鏈路。後設資料載入與傳輸應通過共享適配層接入，不把請求或逐命令適配放入各宿主。

## 結果內容

`TuiRecordContent` 包含 `text`、`search-list`、`resource-preview`、`resource-tree`、`status`、`write-result` 和 `command-help` 七種變體。

- `text` 通過 `format` 區分 `plain` 與 `markdown`，預設為 `plain`。JSON 格式化後作為文本展示。
- 失敗通過 `TuiRecord.status: 'error'` 表達，錯誤正文使用通用文本，不單獨定義錯誤內容變體。
- 命令幫助由共享命令定義生成，其他結果由共享適配層統一轉換；宿主複用轉換結果，不逐條適配命令。

這些變體定義統一展示的目標契約；共享結果轉換和實際檢視仍待實現。

## 可選能力

部分欄位表達的是宿主能力，不傳即降級為對應表現：

| 欄位           | 不傳時              | 傳值時的表現                               |
| -------------- | ------------------- | ------------------------------------------ |
| 空態節點       | 展示 `labels.empty` | 無記錄時展示完整節點，傳 `null` 時隱藏     |
| 檢索層級與型別 | 不顯示對應標籤      | 分別在標題旁和分數旁展示標籤               |
| 分數詳情       | 分數僅顯示文本      | 提供分數文案時，懸停或聚焦顯示宿主詳情內容 |

記錄為 `pending` 時，元件根據 `command` 匹配共享命令定義並選擇對應骨架，無法匹配時使用通用骨架。等待期間可省略 `content`，宿主無需指定骨架形態。

`disabled` 預設為 `false`。設為 `true` 時停用命令輸入與提交，並展示 `labels.unavailableMessage`；未覆蓋該文案時使用內建英文提示。
