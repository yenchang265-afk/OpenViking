# 功能概覽

OpenViking 是面向 AI Agent 的上下文資料庫，將資料、記憶、技能和規則組織成可瀏覽、可檢索的檔案。它為 Agent 提供上下文；Agent 讀取這些內容後，再生成回答或執行任務。

第一次使用，先完成[快速開始](02-quickstart.md)，看到一份能夠核對來源的回答。之後按下面的任務選擇體驗，不必按順序讀完全部文件。

## 從任務出發

| 你的任務 | OpenViking 提供什麼 | 從哪裡開始 |
| --- | --- | --- |
| 根據專案資料回答問題 | 匯入資料、查詢相關內容、讀取原文 | [資料檢索](08-resources.md) |
| 新會話繼續使用已有背景 | 儲存會話並提取記憶，在相關任務中召回 | [記憶使用](09-memory.md) |
| 複用一套工作方法 | 儲存與檢索 Skill，由 Agent 讀取並應用 | [技能使用](10-skills.md) |
| 按規範檢查任務與行動 | 編譯強約束，按當前任務召回規則，供 Agent 核驗 | [規則（Beta）](16-rules.md) |
| 把資料整理成可閱讀的知識 | 按 Skill 編譯為 Wiki 等產物 | [上下文編譯](13-compile.md) |

## 上下文型別

| 型別 | 儲存什麼 | 使用者怎樣確認它有用 |
| --- | --- | --- |
| **資料（Resource）** | 文件、網頁、程式碼等外部資料 | 回答中的關鍵結論能回到來源核對 |
| **記憶（Memory）** | 從會話提取的背景、偏好與經驗 | 新會話不必重複交代，Agent 的新任務確實用到了背景 |
| **技能（Skill）** | 工作流程的指令與配套檔案 | Agent 讀取技能後，產物符合該流程的要求 |
| **規則（Rule，Beta）** | 特定條件下必須遵守的要求，包括義務、禁止項和例外 | Agent 根據任務證據核對適用規則，並據此調整行動或回答 |

這些內容通過 `viking://` URI 定位。知道位置時可以直接讀取；不知道位置時先檢索，再開啟原文。目錄摘要和概覽的生成取決於處理方式與配置，可幫助 Agent 按需載入內容。

**規則：** 例如，“倉庫宣告開源時，必須提供可定位的許可證文本”。你可以將規範中的強約束主動編譯為 Rule，再按具體任務召回。OpenViking 提供規則及其適用條件，Agent 結合當前證據核驗是否滿足要求。規則目前處於 Beta，概念與使用方式見[規則介紹](../concepts/17-rule-scenarios.md)。

## 選擇使用入口

![CLI、已有 Agent 和 VikingBot 連線 OpenViking 上下文服務；閘道器為相容客戶端提供接入路徑。](/quickstart/overview.zh.svg)

| 入口 | 適合怎樣使用 |
| --- | --- |
| **CLI** | 在終端中瀏覽、匯入、檢索與讀取；通過 `ov chat` 使用已啟用的 VikingBot。見 [CLI 入門](05-cli-setup.md) |
| **已有 Agent** | 為日常工具加入上下文與記憶。各外掛的自動捕獲、提交和召回能力不同，安裝後還需驗證新會話行為 |
| **VikingBot** | 使用 OpenViking 內建 Agent 完成問答與工具任務；[快速開始](02-quickstart.md)使用這條路線 |
| **閘道器** | 將相容客戶端的模型請求接入上下文與記憶流程；可通過儲存、提取和召回結果驗證接入效果 |
| **SDK / HTTP** | 在自己的應用中控制匯入、檢索、會話和資料管理流程 |

OpenViking 負責管理和提供上下文，CLI、外掛、閘道器和 Agent 的行為各有邊界。深度接入時再檢視[Agent 整合](../agent-integrations/01-overview.md)、[閘道器接入](12-gateway.md)或 [SDK 與 HTTP](../api/01-overview.md)。

## 體驗技能與知識整理

**技能：** 選擇一個有明確產物的工作流程，安裝 Skill，確認 Agent 能發現並讀取它，再提交一項任務並檢查結果。OpenViking 負責儲存和檢索技能，Agent 負責啟用技能、管理工具許可權並執行任務。跟隨[技能使用](10-skills.md)完成兩組輸入的體驗。

**整理知識：** 準備來源資料，使用 Wiki Skill 執行編譯，等待完成後開啟一篇正文，核對來源和遺漏。使用 Skill 編譯需要已配置的 Compile Runtime，編譯結果可結合原始資料核對。可繼續[上下文編譯](13-compile.md)，生成並閱讀一篇 Wiki。
