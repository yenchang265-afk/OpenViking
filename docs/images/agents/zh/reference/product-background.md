# OpenViking 擴充參考

[接入引導](https://docs.openviking.net/agents/zh/onboarding.md)已包含普通接入需要的解釋。本檔案用於回答使用者追問或處理擴充目標，無需在開始接入時通讀；只查與當前問題有關的部分。知識不代表當前工具一定支援，也不授予執行額外任務的許可。

## 內容型別與處理狀態

- 會話保留支援範圍內的互動過程；記錄存在不證明包含最新訊息。
- 記憶由服務按策略從已提交的會話提取、更新，例如偏好、事項和經驗。記憶可能遺漏或過時，當前使用者要求優先。
- 資料儲存需求、方案、報告等可讀取正文；聊天提到檔案不等於原件上傳，正文入庫也不證明所有附件已備份。
- 技能提供可複用的操作方法；儲存經驗不會自動生成或安裝技能。

訊息寫入、提交提取、提取完成、檢索命中、實際採用是不同狀態。確認狀態要檢查對應結果；不能從檔案存在推斷提取完成，從來源計數推斷答案使用過。

## Hooks、規則與資源消耗

Hooks 是宿主在會話事件發生時執行外掛的機制，用於載入背景、召回、捕獲或觸發提交。具體事件、信任要求、傳送範圍和提交時機以安裝版本為準。客戶端不使用 Hooks 時，以其實際外掛機制說明，不要求使用者尋找不存在的審批入口。

長期規則指導 Agent 何時補查原文、主動儲存哪些內容以及怎樣反饋；不建立後臺檔案監控器，也不保證每輪一定正確執行。已有自動注入足夠時不強制追加查詢，普通對話已捕獲時不再手動儲存一遍。

檢索、注入和整理可能消耗上下文與模型呼叫。按任務相關性取回背景，需要細節時才讀原文；不能承諾固定節省比例。與宿主原生記憶是否重疊，要核對各自作用範圍，不能籠統宣稱替代。

## 目錄與分層讀取

OpenViking 通過目錄和 URI 保留內容歸屬與來源。L0 摘要幫助識別主題，L1 概覽幫助理解內容，L2 原文供細節核對；按問題選擇粒度，不預設載入全部歷史，也不要求使用者先學這些術語。

接續工作先用注入的上下文和相關記憶、筆記，需要細節再讀會話原文；跨多個會話時結合日期、範圍和原記錄核對，不能把最新一個會話當成整個專案。已完成事項不重新開啟，歷史方案不當作當前上線事實，摘要衝突時回查原文。

## 跨 Agent 與身份

另一會話或 Agent 接入同一身份可訪問的內容後，可以用已有背景接續工作。它不即時複製整個聊天視窗、裝置狀態、客戶端規則或未上傳附件；最近尚未提交或處理的內容也可能缺失。

只檢查使用者選定兩端的身份與內容可用性，不為解釋主動安裝第二個客戶端。驗證要由獨立上下文實際取回背景；原聊天讀取成功不等於跨 Agent 驗證成功。

同一地址不等於同一使用者。繫結或切換身份不自動搬運舊資料；需重新對齊讀寫範圍，保留原配置。沒有實際繫結或切換能力時說明限制，不編造命令。

## 偏好、經驗與知識整理

偏好幫助協作符合穩定的表達和判斷方式；僅在當前工作適用時採用，不把一次選擇固化為永久偏好，不為展示效果收集無關個人資訊。

經驗保留有效做法、糾正和適用條件。說明它為什麼適合當前任務，避免機械照搬；是否啟用提取、是否可檢索需核對，不能承諾每輪自動產生經驗。

知識整理／Compile 適合基於多份材料形成有來源的主題知識或 Wiki，通過 `ov` 命令列的 `ov compile` 執行（安裝器的 `cli` 一項裝的就是 `ov`），由服務端的 Compile Runtime 執行，結果寫回 OpenViking。先檢查服務是否支援、來源範圍和輸出位置，再按使用者授權執行；用法見 https://docs.openviking.net/zh/context-compilation/01-overview 。安裝外掛、匯入歷史或生成普通摘要都不等於已執行 Compile。
